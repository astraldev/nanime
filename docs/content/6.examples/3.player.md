Drag the seek bar, skip tracks, change the volume or shuffle the playlist.
There is no audio, and the playhead is an AnimeJS animation. The numbered
controls work, and the greyed ones are decoration.

## Built with

- [`useAnimate`](/composables/use-animate): the playhead, as an animation
  of a number
- [`useAnimeTimeline`](/composables/use-anime-timeline): the artist line
  and total time on each track change
- [`useScrambleText`](/composables/use-scramble-text): the track title
- [`useDraggable`](/composables/use-draggable): the seek and volume thumbs
- [`useAnimatable`](/composables/use-animatable): the level meters
- [`<AnimeTransitionGroup>`](/components/transitions): the playlist
  shuffle
- [`<AnimeTransition>`](/components/transitions): the cover crossfade and
  the play and pause icons
- `spring` from [`#nanime/easings`](/composables/utilities), and `shuffle`
  and `random` from [`#nanime/utils`](/composables/utilities)

## The playhead is an animation

A `reactive({ time: 0 })` object is animated from `0` to the track's length
over that many seconds. Play, pause and seek call the animation's methods,
and `seek()` also works while paused. The params are a getter, so a new
track rebuilds the animation with its own length.

```ts
const playback = useAnimate(clock, () => ({
  time: [0, current.value.duration],
  duration: current.value.duration * 1000,
  ease: 'linear',
  autoplay: false,
  onComplete: next,
}))
```

## One slider component

Seek and volume share a slider. The thumb is a
[`useDraggable`](/composables/use-draggable) limited to the rail with
`y: false` and `velocityMultiplier: 0`, so it stops where it is let go. The
rail is the thumb's width longer than the track it draws, so the thumb's
centre lines up with both ends. The seek bar only seeks on release and shows
the dragged time until then.

## The playlist never reorders on a track change

Picking a track only moves the highlight. A queue that took the track out
and put the old one back at the end would add a leave, a move and an enter
to every change. Shuffle is the one action that reorders, and the group
moves the rows into the new order. The move has no stagger, because the
group staggers every element inside it and a row's text would trail its row.

::collapsible{name="More detail"}
**Sliders.** The value is the draggable's `x` divided by the rail's range.
While the value changes from outside, for example as the playhead moves,
`setX(value * range, true)` moves the thumb without firing the drag
callbacks.

**Cover.** The cover is keyed on the track inside an
[`<AnimeTransition>`](/components/transitions). Both covers sit
`absolute inset-0` in the same box, and the transition runs the old one's
leave and the new one's enter together, so they crossfade over 400ms.

**Title.** [`useScrambleText`](/composables/use-scramble-text) watches the
track's title and scrambles the heading into each new one. The heading
renders the first title with `v-once`, so Vue leaves its text to the
scramble after that.

**Track change.** The artist line and the total time keep their elements,
so a [`useAnimeTimeline`](/composables/use-anime-timeline) built once with
`autoplay: false` holds their fades, and a watcher on the track's id calls
`restart()`. They fade in at 150ms and 250ms, so a change runs in order
rather than all at once.

**Level meters.** Sixteen bars read their heights from one reactive object
animated by [`useAnimatable`](/composables/use-animatable), one property
per bar. While playing, an interval sets each bar to a new `random` height
every 180ms, scaled by the volume. An animatable starts each move from
where the bar is, so the bars never jump. When paused, every bar goes back
to a low resting height.
