## 0.4

### 0.4.0

:changelog-date

- :changelog-tag{type="breaking"} `provideAnimeDefaults()` no longer
  merges `transition`, `transitionGroup` and `layoutGroup` with the same
  one from a call in a parent component. An inner
  `transition: { enterAnimation: 'scale' }` drops the outer `mode`, and
  `mode` then comes from `app.config.ts`. An inner call that does not set
  `transitionGroup` keeps the outer `transitionGroup`.
  :changelog-affects{of="AnimeTransition AnimeTransitionGroup AnimeLayoutGroup"}
- :changelog-tag{type="breaking"} `layoutOptions` no longer merges keys
  with the `layoutOptions` set elsewhere. With
  `{ duration: 400, ease: 'out(3)' }` in `app.config.ts` and
  `:layout-options="{ duration: 200 }"` on
  [`<AnimeLayoutGroup>`](/components/layout-group), 0.3 used
  `duration: 200` and `ease: 'out(3)'`. 0.4 uses `duration: 200` and
  AnimeJS's default ease. The same holds for `provideAnimeDefaults()`.
- :changelog-tag{type="breaking"} The `NanimeAppConfig` type is renamed
  to `NanimeConfig`, matching the `nanime` key in `app.config.ts`. Update
  imports from `#nanime/types` and `nanime/vue`.
- :changelog-tag{type="added"} New `animation` prop on
  [`<AnimeTransition>` and `<AnimeTransitionGroup>`](/components/transition).
  It takes a transition style name, or `{ enter, leave }` on the
  transition and `{ enter, leave, move }` on the group. `move: false`
  turns the move animation off. Each of `enterAnimation`, `leaveAnimation`
  and `moveAnimation` wins over `animation` for the enter, the leave and
  the move respectively. `animation` can also be set in `nanime.components`,
  `provideAnimeDefaults()` and presets.
  :changelog-affects{of="AnimeTransition AnimeTransitionGroup"}
- :changelog-tag{type="added"} New [presets](/guides/presets).
  A preset sets transition styles and defaults for the components and
  composables in one object. Set one for the whole app with
  `nanime.preset` in `app.config.ts`, or for part of the app with
  `provideAnimeDefaults({ preset })`. `nanime/presets/formal`,
  `nanime/presets/elegant` and `nanime/presets/playful` ship with the
  module. Each redefines the built-in style names with its own timing and
  adds a `list` style for `<AnimeTransitionGroup>`. An `<AnimeTransition>`
  with no animation props uses the preset's `fade`. Type a preset of your
  own with `AnimationPreset` from `#nanime/types`.
- :changelog-tag{type="added"} New `waapi` prop on
  [`<AnimeTransition>` and `<AnimeTransitionGroup>`](/components/transition)
  that runs the enter and leave on `waapi.animate()` instead of
  `animate()`. The animation props then take `waapi.animate()` params. A
  style that `waapi.animate()` cannot run falls back to `animate()`.
  :changelog-affects{of="AnimeTransition AnimeTransitionGroup"}
- :changelog-tag{type="added"} Each setting comes from the first of these
  that sets it: the prop or parameter passed, `provideAnimeDefaults()`,
  `app.config.ts`, the preset, the built-in value.
  `<AnimeTransition enter-animation="scale">` enters with `scale` even
  when the preset sets `fade`. A style name is looked up in
  `nanime.transitions`, then the preset, then the built-ins.
  [Defaults](/guides/defaults) has the details.
- :changelog-tag{type="breaking"} The `keepTime` option is now `rebuild`,
  which takes `'restart'`, `'keepTime'` or `'keepValue'`. Replace
  `keepTime: true` with `rebuild: 'keepTime'` in the module options and in
  the composable call. The build logs a warning while `keepTime` is still
  set in `nuxt.config.ts`. `runtimeConfig.public.nanime.keepTime` is not
  read any more. Use `runtimeConfig.public.nanime.rebuild` instead.
  :changelog-affects{of="useAnimate useAnimeTimeline useScrambleText"}
- :changelog-tag{type="added"} [`useAnimate`](/composables/use-animate)
  takes `rebuild: 'keepValue'`, which restarts the animation from the
  values on screen instead of from the original start values. With
  `composition: 'blend'` in the parameters, the old animation keeps
  running while the new one blends onto it. `useAnimeTimeline` and
  `useScrambleText` treat `'keepValue'` as `'restart'`.
- :changelog-tag{type="added"} `nanime.rebuild` in `app.config.ts` sets
  the default `rebuild` for the app, and
  `provideAnimeDefaults({ rebuild })` sets it for part of the app. Both
  override the `rebuild` module option in `nuxt.config.ts`, and a
  composable's own `rebuild` overrides both.
  :changelog-affects{of="useAnimate useAnimeTimeline useScrambleText"}
- :changelog-tag{type="added"} `nanime.composables` in `app.config.ts`
  sets default parameters for `useAnimate` and default options for
  `useDraggable`. `provideAnimeDefaults({ composables })` sets them for
  part of the app. A key passed in the composable call replaces the same
  key in the default, and the default's other keys stay. A key passed as
  `undefined` keeps the default.
  :changelog-affects{of="useAnimate useDraggable"}
- :changelog-tag{type="added"} The build warns when VueUse also
  auto-imports `useAnimate` or `useDraggable`. The new `vueuseAliases`
  module option renames the `nanime` versions so VueUse keeps the plain
  names. See [Use with VueUse](/guides/configuration#use-with-vueuse).
  :changelog-affects{of="useAnimate useDraggable"}
- :changelog-tag{type="added"} `DraggableOptions`, `SplitText`,
  `NanimeLayout` and `ConfigTransitionStyleName` are exported from
  `#nanime/types`.
- :changelog-tag{type="added"} `useDraggable`, `useAnimeScroll` and
  `useSplitText` warn in development when called outside a component,
  where they do nothing.
  :changelog-affects{of="useDraggable useAnimeScroll useSplitText"}
- :changelog-tag{type="fixed"} Items added to a `v-for` template ref list
  now animate. The animation rebuilds with the new list of elements.
  :changelog-affects{of="useAnimate useWaapiAnimate useAnimatable useScrambleText useDraggable"}
- :changelog-tag{type="fixed"} A
  [`useDraggable`](/composables/use-draggable) keeps its position when
  `container` changes.
- :changelog-tag{type="fixed"} A
  [`useAnimeTimeline`](/composables/use-anime-timeline) that calls
  `sync()` plays the synced animation's new values after that animation
  rebuilds.
- :changelog-tag{type="fixed"} `methods.revert()` on
  [`useSplitText`](/composables/use-split-text) empties `lines`, `words`
  and `chars`, and a function in its parameters no longer re-splits the
  text when only that function changes.
- :changelog-tag{type="fixed"} `provideAnimeDefaults()` from `nanime/vue`
  now reaches composables from the Nuxt module in the same app, and the
  other way round.
  :changelog-affects{of="provideAnimeDefaults"}
- :changelog-tag{type="fixed"} Composable targets accept a getter in
  TypeScript, as they already did at runtime.
- :changelog-tag{type="added"} New `nanime/vue` import path for Vue 3 apps
  without Nuxt. It exports the composables, components, types, easings,
  proxies and utilities, but has no auto-imports and no `#nanime/*`
  aliases. `configureNanime(app, config)` takes the same object as the
  `nanime` key in `app.config.ts`. See
  [using `nanime` with Vue](/guides/vue).
- :changelog-tag{type="added"} New `patch-animejs-tracked-layout` agent
  skill for layout scenes with hundreds of elements. It patches the
  installed AnimeJS so `createLayout()` measures only the targets you pass
  it. It ships in `node_modules/nanime/skills`.
- :changelog-tag{type="docs"} The performance and accessibility pages
  moved to [Guides](/guides/configuration), the composable lifecycle page
  to [Composables](/composables/composable-lifecycle) and the comparison
  pages to [Comparisons](/comparisons/vs-nuxt-modules). The old URLs
  redirect. The Examples section is removed, and its URLs redirect to
  [Composables](/composables/introduction).

## 0.3

### 0.3.5

:changelog-date{date="2026-10-26"}

- :changelog-tag{type="fixed"} Resolved
  `TypeError: Cannot read properties of null (reading 'parentNode')` in
  [`AnimeTransition`](/components/transition) with `mode="out-in"`, due
  to the leave animation finishing instantly when reduced motion is on or
  its duration is 0.

### 0.3.4

:changelog-date{date="2026-10-21"}

- :changelog-tag{type="fixed"} Layout items return to their normal place
  when `deps` changes twice in quick succession, instead of staying pinned
  until the group remounts.
  :changelog-affects{of="AnimeLayoutGroup useAnimeLayout"}
- :changelog-tag{type="fixed"}
  [`useAnimeLayout`](/composables/use-anime-layout) `patch()` resolves
  when a later `patch()` or `record()` interrupts its animation, so code
  that awaits it carries on.

### 0.3.3

:changelog-date{date="2026-10-21"}

- :changelog-tag{type="added"} New `completeOnTabHidden` prop that jumps
  running animations to their end when the browser tab is hidden. See
  [Finish animations when the tab is hidden](/components/transition#finish-animations-when-the-tab-is-hidden).
  :changelog-affects{of="AnimeTransition AnimeTransitionGroup AnimeLayoutGroup"}
- :changelog-tag{type="fixed"}
  [`AnimeLayoutGroup`](/components/layout-group) items return to their
  normal place after two `deps` changes in one update, instead of staying
  pinned until the group remounts.

### 0.3.2

:changelog-date{date="2026-10-10"}

- :changelog-tag{type="added"} New `reducedMotion` module option that makes
  animations jump to their end state for visitors who ask for less motion.
  See [Accessibility](/guides/accessibility).
- :changelog-tag{type="added"}
  [`AnimeTransitionGroup`](/components/transition-group#api)
  takes `deps` and `shallow`, so it measures its layout only when items are
  added, removed or reordered, or when a `deps` value changes.
- :changelog-tag{type="fixed"}
  [`useSplitText`](/composables/use-split-text) keeps its split when a
  parent re-render passes the same parameters as a new object.
- :changelog-tag{type="performance"} The CSS that the transition
  components and layout groups rely on no longer loads on every page. It
  ships with the code that uses it: the three components and
  [`useAnimeLayout`](/composables/use-anime-layout).
- :changelog-tag{type="packaging"} Importing from `#nanime/composables`
  now adds the same code as auto-imports. Before, it also kept the
  top-level code of composables you don't use.
- :changelog-tag{type="docs"} The
  [performance guide](/guides/performance#add-deps-to-groups)
  and the [`AnimeLayoutGroup` page](/components/layout-group#choosing-between-the-two-groups)
  explain when to pass `deps` to `AnimeTransitionGroup` and
  `AnimeLayoutGroup`.

### 0.3.1

:changelog-date{date="2026-09-29"}

- :changelog-tag{type="fixed"} Fixes the Tailwind CSS v3 build error introduced in 0.3.0.
- :changelog-tag{type="fixed"} Selector lists in `elements`, such as

### 0.3.0

:changelog-date{date="2026-09-29"}

- :changelog-tag{type="breaking"}
  [`useAnimeScroll`](/composables/use-anime-scroll) takes a parameters
  object instead of a ref or getter. Pass template refs as `target` and
  `container` directly, and refs for `enter`, `leave`, `repeat` and `axis`
  update the observer without rebuilding it.
- :changelog-tag{type="breaking"} After a leave, the styles it animated are
  removed, so a `v-show` or KeepAlive element comes back in its normal
  place. An enter with only an end value, such as `{ opacity: 1 }`, now
  starts from the element's own style. Give it a start value:
  `{ opacity: [0, 1] }`.
  :changelog-affects{of="AnimeTransition AnimeTransitionGroup"}
- :changelog-tag{type="breaking"} `patch()` on a
  [`useAnimeLayout`](/composables/use-anime-layout) returns
  `Promise<void>` instead of the timeline. `await layout.patch(...)` still
  resolves when the animation finishes. Read the timeline from
  `layout.timeline`.
- :changelog-tag{type="breaking"} TypeScript rejects `duration`, `delay`
  and `ease` in the animation options of
  [`useScrambleText`](/composables/use-scramble-text), where AnimeJS ignored
  them. Put them in the scramble options.
- :changelog-tag{type="added"} New
  [`AnimeLayoutGroup`](/components/layout-group) component that animates its
  children to their new position and size when `deps` change.
- :changelog-tag{type="added"} Default props for `nanime` components, set in
  `app.config.ts` or for part of the app. See
  [component defaults](/guides/defaults#set-app-wide-defaults).
- :changelog-tag{type="added"} New `html` option in
  [`useSplitText`](/composables/use-split-text) for text that changes. See
  [render changing text with v-once](/composables/use-split-text#render-changing-text-with-v-once).
- :changelog-tag{type="added"} `AutoLayoutParams`,
  `LayoutAnimationParams`, `AnimeScrollParams`, `AnimeScrollTarget` and
  `ScrambleAnimationParams` are exported from `#nanime/types`.
- :changelog-tag{type="fixed"} Changing a field of a `reactive()`
  parameters object, such as `params.x = 200`, now rebuilds and restarts
  the animation, as it does for a ref or getter. If you change parameters
  often, pass `keepTime: true` to keep the playhead, or use `useAnimatable`
  for values that change every frame.
  :changelog-affects{of="useAnimate useAnimeTimeline useSplitText useScrambleText useAnimeScroll useAnimeLayout"}
- :changelog-tag{type="fixed"} Calling a method inside your component's
  `onMounted`, such as `animation.seek(500)` or `layout.patch(update)`, now
  takes effect. The animation is created before your `onMounted` runs.
  :changelog-affects{of="useAnimate useAnimatable useAnimeLayout"}
- :changelog-tag{type="fixed"} Calling `sync()` on a
  [`useAnimeTimeline`](/composables/use-anime-timeline) with a `useAnimate`
  declared after it now syncs that animation.
- :changelog-tag{type="fixed"} A
  [`useAnimeTimeline`](/composables/use-anime-timeline) carries on when its
  parameters change. With `keepTime`, it keeps its playhead and stays
  playing or paused. With `autoplay: useAnimeScroll(...)`, it keeps
  following the scroll.
- :changelog-tag{type="fixed"} When the target, `trigger` or `container`
  ref of a [`useDraggable`](/composables/use-draggable) points to a new
  element, dragging moves to that element. A target that is `null` at mount
  no longer throws.
- :changelog-tag{type="fixed"} A [`useDraggable`](/composables/use-draggable)
  stays disabled after `disable()` when it rebuilds.
- :changelog-tag{type="fixed"} Snapping in
  [`useDraggable`](/composables/use-draggable) works when `snap` is a ref or
  a function that takes the draggable. A top-level `snap` still applies when
  you also pass an `x` or `y` object.
- :changelog-tag{type="fixed"} When the target of a
  [`useAnimatable`](/composables/use-animatable) changes, the old element
  goes back to its original styles.
- :changelog-tag{type="fixed"} Animations added with `link()` stay linked
  when the parameters of a
  [`useAnimeScroll`](/composables/use-anime-scroll) change.
- :changelog-tag{type="fixed"} When the target of a
  [`useSplitText`](/composables/use-split-text) becomes `null`, the original
  text comes back and `lines`, `words` and `chars` are emptied.
- :changelog-tag{type="fixed"} Items in
  [`AnimeTransitionGroup`](/components/transition-group) with a CSS
  `transition` no longer animate twice after a move.
- :changelog-tag{type="fixed"} Elements keep their shape while a layout
  animates. A box with padding keeps its size, one-line text stays on one
  line, inline text keeps its line height, and an icon in a button next to
  text, such as the x on a tag chip, stays in its button.
  :changelog-affects{of="AnimeTransitionGroup useAnimeLayout"}
- :changelog-tag{type="fixed"} A
  [`useAnimeLayout`](/composables/use-anime-layout) no longer rebuilds in
  the middle of an animation and cuts it short.
- :changelog-tag{type="fixed"} TypeScript accepts a getter as the
  [`useAnimeLayout`](/composables/use-anime-layout) target and as the
  [`useDraggable`](/composables/use-draggable) `trigger`.

## 0.2

### 0.2.1

:changelog-date{date="2026-09-25"}

- :changelog-tag{type="fixed"} With pnpm, `nuxi dev` warned that none of
  the `animejs/*` entries `nanime` adds to `vite.optimizeDeps.include`
  could be resolved, and Vite skipped pre-bundling them. The entries now
  point Vite at the AnimeJS copy inside `nanime`, so they resolve whether
  or not your app depends on `animejs` itself.
- :changelog-tag{type="fixed"} Items in
  [`<AnimeTransitionGroup>`](/components/transition) lost an inline
  `background`, `color` or `border-radius` when the other items finished
  moving while they were still entering or leaving. They now keep it.
- :changelog-tag{type="packaging"} `animejs/easings`, which
  `#nanime/easings` re-exports, is now pre-bundled too.
- :changelog-tag{type="docs"} The [`useAnimatable`](/composables/use-animatable)
  page now says that a number beside a property in the options is that
  property's tween duration, not a value to animate to.

### 0.2.0

:changelog-date{date="2026-09-24"}

- :changelog-tag{type="breaking"} [`useAnimeLayout`](/composables/use-anime-layout)
  returns the AnimeJS layout itself instead of a wrapper object. Read
  properties straight off it rather than from `.properties`. `animate()`
  no longer takes a callback: use the timeline it returns, for example
  `layout.animate().then(done)`.
- :changelog-tag{type="added"} Added
  [`<AnimeTransition>` and `<AnimeTransitionGroup>`](/components/transition),
  built on Vue's `<Transition>` and `<TransitionGroup>`. They run enter
  and leave with AnimeJS instead of CSS classes. In a list, the other
  items slide to their new places through AnimeJS layout, and `stagger()`
  delays work across items that enter or leave in the same update.
- :changelog-tag{type="added"} The transition components take
  `enter-animation`, `leave-animation` and `move-animation`, as AnimeJS
  params or the name of a [transition style](/components/transition-styles).
  Seven styles are built in, such as `fade` and `slide-up`, and you can add
  your own under `nanime.transitions` in `app.config.ts`.
- :changelog-tag{type="added"} New `components` module option. Set it to
  `false` to skip registering the transition components.
- :changelog-tag{type="added"} [`useAnimeLayout`](/composables/use-anime-layout)
  now has a docs page and a `patch()` method. Pass it the function that
  changes your state, and it records the layout, runs the function, waits
  for Vue to update the DOM, then animates. The layout also rebuilds only
  when its target or parameters change, not on every reactive update.
- :changelog-tag{type="added"} Hovering a composable, a component prop or a
  `#nanime/types` type in your editor now shows what it does and its
  default.
- :changelog-tag{type="fixed"} Replacing an element inside a composable's
  parameters, for example the target of a timeline step, was ignored. The
  change check treated any two elements as equal, so the animation kept
  the old one.
- :changelog-tag{type="fixed"} Parameters holding reactive state or an
  AnimeJS instance could overflow the stack during the change check.
- :changelog-tag{type="fixed"} `import { useAnimate } from '#nanime/composables'`
  failed, so turning off auto-imports with `composables: false` left no
  way to import the composables.
- :changelog-tag{type="packaging"} `lodash-es` and `tailwind-merge` are no
  longer added to Vite's pre-bundled dependencies. `nanime` never used
  them.
- :changelog-tag{type="docs"} New [Components](/components/transition)
  section. The Misc pages are now one [Utilities](/composables/utilities)
  page under Composables.
- :changelog-tag{type="docs"} New Media library
  example. Drag to bin and
  Loading sequence are rebuilt with the
  transition components. The Timeline storyboard and Text magnet examples
  are gone.
- :changelog-tag{type="docs"} New pages comparing `nanime` with
  [Nuxt modules](/comparisons/vs-nuxt-modules) and
  [Vue packages](/comparisons/vs-vue-packages) for AnimeJS.
- :changelog-tag{type="docs"} Every page has its own search title and
  description. Code blocks in live demos highlight correctly again.

## 0.1

### 0.1.14

:changelog-date{date="2026-09-24"}

- :changelog-tag{type="fixed"} Fixed `reactive is not defined` runtime crashes caused by Nuxt auto-imports in `node_modules`.

### 0.1.13

:changelog-date{date="2026-09-22"}

- :changelog-tag{type="added"} Added
  [`useAnimeScroll`](/composables/use-anime-scroll) composable wrapping
  AnimeJS `onScroll()`. Owns the observer's lifecycle, and pass it to an
  animation's `autoplay` to drive it from scroll position.
- :changelog-tag{type="added"} [`keepTime`](/guides/configuration#set-module-options)
  option lets a running animation keep its playhead across a rebuild
  instead of resetting. Defaults to `false`, matching prior behavior. Set
  it per call, or `nanime.keepTime: true` in `nuxt.config`, to opt in.
- :changelog-tag{type="added"} [`useSplitText`](/composables/use-split-text)
  exposes `refresh()`, for re-splitting after the element's text changes.
- :changelog-tag{type="added"} Composable return values are recognised by
  proxy marker wherever AnimeJS accepts an instance, not by parameter
  name, so they work directly in `autoplay` or `.sync()`.
- :changelog-tag{type="added"} `#nanime/types` adds the scroll and
  remaining SVG types.
- :changelog-tag{type="fixed"} [`useSplitText`](/composables/use-split-text)
  returned an empty `methods` object. Property extraction now walks the
  prototype chain instead of `Object.keys`.
- :changelog-tag{type="fixed"} `useSplitText` re-splits current text and
  watches explicit sources, fixing a mount-time runaway.
- :changelog-tag{type="fixed"} A timeline no longer empties itself when
  its parameters change. Buffered calls replay on rebuild.
- :changelog-tag{type="fixed"} [`useAnimate`](/composables/use-animate)
  now watches both `target` and `parameters`, not just `target`.
- :changelog-tag{type="fixed"} An animation whose parameters carry
  another composable's instance is cancelled, not reverted, on rebuild,
  since `Timer.revert()` cascades into the linked `ScrollObserver`.
- :changelog-tag{type="fixed"} `autoplay` resolved to `null` when the
  scroll observer did not exist yet, and never relinked afterwards.
- :changelog-tag{type="performance"} Rebuilds are skipped when the new
  parameters match the old ones. Checking for a match takes about 0.06
  microseconds, next to nothing compared to the roughly 2.8 milliseconds
  a full rebuild costs at 200 targets.
- :changelog-tag{type="docs"} Every page rewritten for shorter, plainer
  sentences, with [composable pages](/composables/introduction) following
  one layout.
- :changelog-tag{type="docs"} Corrected wrong API claims across
  [composable pages](/composables/introduction) (return type, buffering,
  rebuild triggers), and wrong
  upstream AnimeJS defaults for `ease`, `splitText` `words`, and
  `onScroll` thresholds, now read from the installed package.
- :changelog-tag{type="docs"} Corrected example pages against their
  components (timeline count, drag handle, scramble target), and added a
  Scroll road trip showcase.
- :changelog-tag{type="docs"} Tightened showcase page prose for a
  consistent register, and fixed two factual errors in the text magnet
  page.

### v0.0.11...v0.1.12

:changelog-date{date="2026-08-23"}

- :changelog-tag{type="breaking"} Removed
  `<ATransitionSlide>`/`<ATransitionScale>`, the `components`/`prefix`
  module options, and the `#nanime/components` alias. They broke under
  `useAnimeLayout`, so `nanime` is composables-only until layout handling
  is sorted out.
- :changelog-tag{type="breaking"} [`useDraggable`](/composables/use-draggable)
  now returns a buffered proxy (`BufferedProxyReturns<T>` rather than
  `ProxyReturns<T>`). Methods called before the instance exists are
  replayed once it is created, so `draggable.disable()` no longer needs
  optional chaining, and code that used it still compiles.
- :changelog-tag{type="breaking"}
  [`useAnimeTimeline`](/composables/use-anime-timeline) now buffers the
  whole timer control surface, not just the builder methods, so calls
  like `play`, `pause`, and `seek` are safe before mount. Its return type
  changed the same way as `useDraggable`'s.
- :changelog-tag{type="packaging"} `@vueuse/core` is no longer a
  dependency at all. The three helpers the runtime used from it

  so installing `nanime` no longer pulls VueUse in.
- :changelog-tag{type="packaging"} `animejs` and `defu` are plain
  dependencies now, and `vue` is the only peer left. Both are imported at
  runtime, so nothing has to be installed alongside `nanime` any more.

  alias re-exporting `morphTo`, `createMotionPath` and `createDrawable`,

  text and SVG proxies.
- :changelog-tag{type="added"} [`#nanime/utils`](/composables/utilities) also
  exports `animate` and `createTimer` for imperative work outside a
