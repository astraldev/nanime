Two ways to add `nanime` to a Nuxt project.

## Automatic

`nuxi` installs the package and adds it to `nuxt.config.ts` in one command.

::code-group
```bash [npx]
npx nuxi module add nanime
```

```bash [pnpm]
pnpm dlx nuxi module add nanime
```

```bash [bun]
bun x nuxi module add nanime
```
::

## Manual

::steps
### Install the package

  :::code-group
  ```bash [npm]
  npm install nanime
  ```

  ```bash [pnpm]
  pnpm add nanime
  ```

  ```bash [bun]
  bun add nanime
  ```
  :::

### Register the module

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nanime']
})
```
::

Nuxt auto-imports the composables from here, so there is nothing else to
configure.
