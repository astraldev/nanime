Two ways to add `nanime` to a Nuxt project.

## Automatic

`nuxi` installs the package and adds it to `nuxt.config.ts` in one command.

::code-group
```bash [npx]
npx nuxi module add nanime
```

```bash [pnpm]
pnpm dlx nuxi module add nanime
```

```bash [bun]
bun x nuxi module add nanime
```
::

## Manual

::steps
### Install the package

  :::code-group
  ```bash [npm]
  npm install nanime
  ```

  ```bash [pnpm]
  pnpm add nanime
  ```

  ```bash [bun]
  bun add nanime
  ```
  :::

### Register the module

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nanime']
})
```
::

Nuxt auto-imports the composables and registers `<AnimeTransition>` and
`<AnimeTransitionGroup>` from here, so there is nothing else to configure.
The [`composables` and `components` options](/getting-started/configuration)
turn either off, and
[`app.config.ts`](/getting-started/configuration#app-config) holds custom
transition styles.

## Use with AI agents

Two ways to give a coding agent these docs:

- **llms.txt**: the docs as plain text, at [/llms.txt](https://nanimejs.netlify.app/llms.txt) (index) and [/llms-full.txt](https://nanimejs.netlify.app/llms-full.txt) (every page).
- **MCP**: add `https://nanimejs.netlify.app/mcp` as an MCP server so the agent can search the docs itself.
