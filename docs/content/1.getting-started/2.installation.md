Add `nanime` with one `nuxi` command, or install and register it by hand.

## Requirements

- Nuxt 3.13.5 or later, including Nuxt 4
- Vue 3.5 or later

## Add it with nuxi

`nuxi` installs the package and adds `nanime` to `modules` in
`nuxt.config.ts`.

::code-group
```bash [npx]
npx nuxi module add nanime
```

```bash [pnpm]
pnpm dlx nuxi module add nanime
```

```bash [bun]
bun x nuxi module add nanime
```
::

## Install it by hand

::steps
### Install the package

  :::code-group
  ```bash [npm]
  npm install nanime
  ```

  ```bash [pnpm]
  pnpm add nanime
  ```

  ```bash [bun]
  bun add nanime
  ```
  :::

### Register the module

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nanime']
})
```
::

No other setup is needed. The composables, `<AnimeTransition>`,
`<AnimeTransitionGroup>` and `<AnimeLayoutGroup>` now work in every
component without an import.

## Run your first animation

This component slides a box 200px to the right and back on a loop:

```vue [app.vue]
<script setup lang="ts">
const box = useTemplateRef('box')

useAnimate(box, { x: 200, loop: true, alternate: true })
</script>

<template>
  <div ref="box" style="width: 48px; height: 48px; background: #42b883" />
</template>
```

In Nuxt 4 this file is `app/app.vue`. Nuxt 3 reads `app.vue` at the
project root.

## Run your first transition

`<AnimeTransition>` animates an element that `v-if`, `v-show` or a changed
`key` adds and removes.

```vue [app.vue]
<script setup lang="ts">
const open = ref(true)
</script>

<template>
  <button @click="open = !open">Toggle</button>
  <AnimeTransition animation="slide-up">
    <div v-if="open" style="width: 48px; height: 48px; background: #42b883" />
  </AnimeTransition>
</template>
```

Without `animation`, the element fades in over 300ms and out over 200ms.
The other names are `slide-down`, `slide-left`, `slide-right`, `scale` and
`swap`. For lists, swap in `<AnimeTransitionGroup>` and give each `v-for`
item a `key`.

## If nothing moves

| Symptom | Cause | Fix |
| :-- | :-- | :-- |
| `useAnimate is not defined` | The module is not registered, or `composables` is `false` | Add `'nanime'` to `modules`, or import from `#nanime/composables` |
| The animation runs but nothing is visible | The element has no size | Give the element a width, a height and a colour |
| A selector string animates the wrong elements | A selector matches the whole document | Pass a template ref instead |

## Not using Nuxt

Import the composables and components from `nanime/vue`. There are no
auto-imports, and you register each component by hand. See
[Vue without Nuxt](/guides/vue).

## Use with AI agents

### Install the agent skill

The skill teaches your coding agent the `nanime` composables and
transition components. With it, the agent calls `useAnimate()` instead of
calling `animate()` inside `onMounted`.

```bash
npx skills add astraldev/nanime --skill nanime
```

### Connect the docs MCP server

The MCP server lets the agent search these docs itself.

::code-group
```bash [Claude Code]
claude mcp add --transport http nanime https://nanimejs.netlify.app/mcp
```

```json [Cursor (.cursor/mcp.json)]
{
  "mcpServers": {
    "nanime": { "url": "https://nanimejs.netlify.app/mcp" }
  }
}
```

```json [VS Code (.vscode/mcp.json)]
{
  "servers": {
    "nanime": { "type": "http", "url": "https://nanimejs.netlify.app/mcp" }
  }
}
```
::

### Share the docs as plain text

For an agent without MCP, paste the URL of
[/llms-full.txt](https://nanimejs.netlify.app/llms-full.txt){target="_blank"}
(every page in one file) or
[/llms.txt](https://nanimejs.netlify.app/llms.txt){target="_blank"}
