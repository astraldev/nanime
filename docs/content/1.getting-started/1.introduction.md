# Introduction

[nanime]{.text-primary} is a Nuxt module that brings
[AnimeJS](https://animejs.com/) into Vue and Nuxt as composables you can
call straight from `setup()`.

## Why?

AnimeJS needs the DOM. In Nuxt, that means an `onMounted` guard, cleanup on
unmount, and preventing hydration mismatches. You write that same handful of
lines in every component that animates anything. `nanime` keeps them in the
composables instead.

## What you get

- **SSR safe**: Nothing runs on the server, so you do not need `onMounted`
  wrappers or `<ClientOnly>` checks.
- **Reactive**: Targets accept a `ref`, a `computed` or a getter. The
  animation rebuilds when targets change.
- **Auto-imported**: The module registers them, so there is nothing to import
  and no plugin to set up.

## The composables

| Composable                                             | Wraps                 | What it does                                               |
| ------------------------------------------------------ | --------------------- | ---------------------------------------------------------- |
| [`useAnimate`](/composables/use-animate)               | `animate()`           | CSS properties, transforms, SVG and plain JS objects       |
| [`useWaapiAnimate`](/composables/use-waapi-animate)    | `waapi.animate()`     | Web Animations API, off the main thread                    |
| [`useAnimatable`](/composables/use-animatable)         | `createAnimatable()`  | Property setters that tween, for values that change a lot  |
| [`useAnimeTimeline`](/composables/use-anime-timeline)  | `createTimeline()`    | Several animations on one clock                            |
| [`useSplitText`](/composables/use-split-text)          | `splitText()`         | Text split into lines, words and characters                |
| [`useScrambleText`](/composables/use-scramble-text)    | `scrambleText()`      | Scramble and reveal effects, with reactive text            |
| [`useDraggable`](/composables/use-draggable)           | `createDraggable()`   | Dragging, with snap, bounds and axis constraints           |
