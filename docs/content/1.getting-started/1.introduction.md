`nanime` is a Nuxt module for
[AnimeJS](https://animejs.com/){target="_blank"} v4. It wraps AnimeJS
functions in composables, so `animate()` becomes `useAnimate()`.
`<AnimeTransition>` and `<AnimeTransitionGroup>` animate elements in and
out.

This component slides a box 200px to the right and back on a loop:

```vue
<script setup lang="ts">
const box = useTemplateRef('box')

useAnimate(box, { x: 200, loop: true, alternate: true })
</script>

<template>
  <div ref="box" />
</template>
```

## What does the module handle?

- **SSR**: composables wait for the element to mount, so nothing runs on
  the server.
- **Cleanup**: the animation reverts when the component unmounts.
- **Reactivity**: the animation rebuilds when a `ref`, `computed` or
  getter passed as the target or parameters changes.
- **Imports**: composables and components are auto-imported.
