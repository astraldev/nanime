`nanime` is a composable based wrapper for [AnimeJS](https://animejs.com/){target="_blank"} v4.
It wraps functions and utilities in composables, so `animate()` becomes `useAnimate()`, and provides
some components for common animation use cases

> Requires Nuxt 3.13.5 or later and Vue 3.5 or later.

## Batteries included

- Nine composables, one per AnimeJS API:
  - [`useAnimate`](/composables/use-animate)
  - [`useWaapiAnimate`](/composables/use-waapi-animate),
  - [`useAnimatable`](/composables/use-animatable),
  - [`useAnimeTimeline`](/composables/use-anime-timeline),
  - [`useSplitText`](/composables/use-split-text),
  - [`useScrambleText`](/composables/use-scramble-text),
  - [`useDraggable`](/composables/use-draggable),
  - [`useAnimeScroll`](/composables/use-anime-scroll) and
  - [`useAnimeLayout`](/composables/use-anime-layout).
- Three components:
  - [`<AnimeTransition>`](/components/transition),
  - [`<AnimeTransitionGroup>`](/components/transition-group) and
  - [`<AnimeLayoutGroup>`](/components/layout-group).
- Seven built-in transition styles:
  - `fade`
  - `slide-up`, `slide-down`, `slide-left` and `slide-right`
  - `scale`
  - `swap`

## What it handles for you

- **SSR**: Animations will only take place when the component itself is available,
- **Cleanup**: The animations will also clean itself up once its scope (if called on setup) is disposed. See
  [instant play](/composables/composable-lifecycle#instant-play) if you will be calling composables in functions.
- **Reactivity**: The composables will react to changes in reactive values, such as targets, and animation params
- **Auto imports**: composables and components are auto-imported in nuxt
