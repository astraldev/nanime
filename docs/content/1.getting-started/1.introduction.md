`nanime` is a Nuxt module for
[AnimeJS](https://animejs.com/){target="_blank"} v4. It wraps AnimeJS
functions in composables, so `animate()` becomes `useAnimate()`, and adds
`<AnimeTransition>` and `<AnimeTransitionGroup>` for elements that enter
and leave.

Requires Nuxt 3.13.5 or later and Vue 3.5 or later.

## What ships

- Nine composables, one per AnimeJS API:
  [`useAnimate`](/composables/use-animate),
  [`useWaapiAnimate`](/composables/use-waapi-animate),
  [`useAnimatable`](/composables/use-animatable),
  [`useAnimeTimeline`](/composables/use-anime-timeline),
  [`useSplitText`](/composables/use-split-text),
  [`useScrambleText`](/composables/use-scramble-text),
  [`useDraggable`](/composables/use-draggable),
  [`useAnimeScroll`](/composables/use-anime-scroll) and
  [`useAnimeLayout`](/composables/use-anime-layout).
- Three components: [`<AnimeTransition>`](/components/transitions),
  [`<AnimeTransitionGroup>`](/components/transition-group) and
  [`<AnimeLayoutGroup>`](/components/layout-group).
- Seven built-in transition styles: `fade`, `slide-up`, `slide-down`,
  `slide-left`, `slide-right`, `scale` and `swap`. See
  [transition styles](/components/transition-styles).
- A `nanime/vue` entry for Vue 3 apps without Nuxt. See
  [Vue without Nuxt](/guides/vue).

This component slides a box 200px to the right and back on a loop:

```vue [app.vue]
<script setup lang="ts">
const box = useTemplateRef('box')

useAnimate(box, { x: 200, loop: true, alternate: true })
</script>

<template>
  <div ref="box" style="width: 48px; height: 48px; background: #42b883" />
</template>
```

## What does the module handle?

- **SSR**: composables wait for the element to mount, so no animation
  touches the DOM on the server.
- **Cleanup**: the animation reverts when the component unmounts, when the
  composable is called in `setup()`. Called in an event handler, a
  composable builds the animation once and never reverts it. See
  [instant play](/composables/introduction#instant-play).
- **Reactivity**: the animation rebuilds when a `ref`, `computed` or
  getter passed as the target or parameters changes.
- **Imports**: composables and components are auto-imported.
