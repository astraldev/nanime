`nanime` runs with no configuration. One option exists if the default does
not fit.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nanime'],
  nanime: {
    // options go here
  }
})
```

### `composables`
- **Type**: `boolean`
- **Default**: `true`

Whether the module auto-imports its composables. Set it to `false` to
import them yourself:

```ts
nanime: {
  composables: false
}
```

```ts
import { useAnimate } from '#nanime/composables'
```
