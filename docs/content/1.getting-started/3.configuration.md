`nanime` runs with no configuration. Three options exist if the defaults do
not fit.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nanime'],
  nanime: {
    // options go here
  }
})
```

### `composables`
- **Type**: `boolean`
- **Default**: `true`

Whether the module auto-imports its composables. Set it to `false` to
import them yourself:

```ts
nanime: {
  composables: false
}
```

```ts
import { useAnimate } from '#nanime/composables'
```

### `components`
- **Type**: `boolean`
- **Default**: `true`

Whether the module registers
[`<AnimeTransition>`](/components/transitions) and
[`<AnimeTransitionGroup>`](/components/transitions#lists) as global
components, along with the small stylesheet they use. Set it to `false` if
you do not use them:

```ts
nanime: {
  components: false
}
```

### `keepTime`
- **Type**: `boolean`
- **Default**: `false`

The default for every composable's own `keepTime` option. `true` carries an
animation's playhead across a rebuild, so it continues instead of
restarting when its reactive inputs change. A composable's own third
argument still wins over this:

```ts
nanime: {
  keepTime: true
}
```

```ts
// restarts on rebuild even though the module default is true
useAnimate(target, { x: 100 }, { keepTime: false })
```

## App config

Custom [transition styles](/components/transition-styles) go under the
`nanime.transitions` key in `app.config.ts`, not `nuxt.config.ts`. App
config is bundled with the app, so styles can hold functions, such as a
random `delay`.

```ts [app/app.config.ts]
export default defineAppConfig({
  nanime: {
    transitions: {
      pop: {
        enter: { opacity: [0, 1], scale: [0.4, 1], duration: 700 },
        leave: { opacity: 0, scale: 0.4, duration: 250 },
      },
    },
  },
})
```

Each style can set `enter`, `leave` and `move`. A style with a built-in
name, such as `fade`, replaces the built-in.
