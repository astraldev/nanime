`nanime` runs with no configuration. Two options exist if the defaults do
not fit.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nanime'],
  nanime: {
    // options go here
  }
})
```

### `composables`
- **Type**: `boolean`
- **Default**: `true`

Whether the module auto-imports its composables. Set it to `false` to
import them yourself:

```ts
nanime: {
  composables: false
}
```

```ts
import { useAnimate } from '#nanime/composables'
```

### `keepTime`
- **Type**: `boolean`
- **Default**: `true`

The default for every composable's own `keepTime` option. `true` carries an
animation's playhead across a rebuild, so it continues instead of
restarting when its reactive inputs change. A composable's own third
argument still wins over this:

```ts
nanime: {
  keepTime: false
}
```

```ts
// restarts on rebuild even though the module default is false
useAnimate(target, { x: 100 }, { keepTime: true })
```
