`nanime` runs with no configuration. The module options below exist for
the cases where the defaults do not fit.

## Module Options

Options go on the `nanime` key in `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nanime'],
  nanime: {
    // Options
  }
})
```

### `composables`
- **Type**: `boolean`
- **Default**: `true`

Whether the module auto-imports its composables. Set it to `false` to
import them from `#nanime/composables` yourself.

```ts
nanime: {
  composables: false // Disable auto-imports
}
```
