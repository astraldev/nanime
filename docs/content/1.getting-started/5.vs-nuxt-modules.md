This page compares `nanime` with AnimeJS on its own and with
`@hypernym/nuxt-anime`, as of September 2026. If something is out of
date, [open an issue](https://github.com/astraldev/nanime/issues){target="_blank"}.
For Vue packages, see
[Compared with Vue packages](/getting-started/vs-vue-packages).

## How do the Nuxt modules compare?

| | `nanime` | `@hypernym/nuxt-anime` |
| :-- | :-- | :-- |
| AnimeJS version | [v4]{.comparison-good} | v3 |
| Latest release | [Sep 2026]{.comparison-good} | Sep 2023 |
| [Auto-imports](/getting-started/installation) | [Yes]{.comparison-good} | Opt-in |
| Safe during SSR, cleans up on unmount | [Yes]{.comparison-good} | Manual |
| Rebuilds when a `ref` changes | [Yes]{.comparison-good} | No |
| Keeps the playhead on rebuild | [Yes]{.comparison-good} | No |
| [Animate](/composables/use-animate), [timeline](/composables/use-anime-timeline), [SVG helpers](/composables/utilities#proxies) | Yes | Yes |
| [WAAPI](/composables/use-waapi-animate), [draggable](/composables/use-draggable), [text](/composables/use-split-text), [scroll](/composables/use-anime-scroll), [layout](/composables/use-anime-layout) and more | [Yes]{.comparison-good} | No |
| [Transition components](/components/transitions) | [Yes]{.comparison-good} | No |

::tip
Green marks the rows where the two modules differ. "Manual" means the
module leaves that step to your own code.
::

[`@hypernym/nuxt-anime`](https://github.com/hypernym-studio/nuxt-anime){target="_blank"}
provides the AnimeJS v3 `anime` function as `$anime`. With
`composables: true`, it also auto-imports it as `useAnime`. AnimeJS v4
split `anime()` into functions like `animate()` and `createTimeline()`, so
v3 code needs changes to run on v4.

[`nuxt-animejs`](https://www.npmjs.com/package/nuxt-animejs){target="_blank"} is a Nuxt 2
module built on a `v-anime` directive. Its README says it is no longer
maintained.

## Which should you pick?

- `nanime` for a Nuxt app on AnimeJS v4, especially one that animates
  lists or values that change.
- AnimeJS on its own for one or two animations that never change.
- `@hypernym/nuxt-anime` for an app that stays on AnimeJS v3.
- A package from [Compared with Vue packages](/getting-started/vs-vue-packages)
  for a Vue app without Nuxt.

## How does a staggered entrance compare?

The three versions below do the same thing. Four cards fade up one after
another on mount, and a Replay button plays the entrance again:

::code-group
```vue [nanime]
<script setup lang="ts">
import { stagger } from '#nanime/utils'

const cards = useTemplateRef('cards')

const entrance = useAnimate(cards, {
  translateY: [16, 0],
  opacity: [0, 1],
  delay: stagger(80),
})
</script>

<template>
  <button @click="entrance.restart()">Replay</button>
  <div v-for="n in 4" :key="n" ref="cards" class="card" />
</template>
```

```vue [AnimeJS on its own]
<script setup lang="ts">
import { animate } from 'animejs/animation'
import { stagger } from 'animejs/utils'
import type { JSAnimation } from 'animejs'

const cards = useTemplateRef('cards')
let entrance: JSAnimation | undefined

onMounted(() => {
  if (!cards.value) return
  entrance = animate(cards.value, {
    translateY: [16, 0],
    opacity: [0, 1],
    delay: stagger(80),
  })
})

onBeforeUnmount(() => entrance?.revert())
</script>

<template>
  <button @click="entrance?.restart()">Replay</button>
  <div v-for="n in 4" :key="n" ref="cards" class="card" />
</template>
```

```vue [@hypernym/nuxt-anime]
<script setup lang="ts">
import type { AnimeInstance } from 'animejs'

const { $anime } = useNuxtApp()

const cards = useTemplateRef('cards')
let entrance: AnimeInstance | undefined

onMounted(() => {
  if (!cards.value) return
  entrance = $anime({
    targets: cards.value,
    translateY: [16, 0],
    opacity: [0, 1],
    delay: $anime.stagger(80),
  })
})

onBeforeUnmount(() => cards.value && $anime.remove(cards.value))
</script>

<template>
  <button @click="entrance?.restart()">Replay</button>
  <div v-for="n in 4" :key="n" ref="cards" class="card" />
</template>
```
::

[`useAnimate`](/composables/use-animate) waits for the cards to mount and
reverts the animation on unmount. `entrance` is the AnimeJS animation, so
methods like `restart()` work as the AnimeJS docs describe.

## How do lists animate in and out?

[`<AnimeTransitionGroup>`](/components/transitions#lists) animates items
that enter and leave a `v-for` list. AnimeJS
[layout](/composables/use-anime-layout) slides the other items to their
new places. The three versions below scale items in and out:

::render-code-block-preview
---
code: false

::

::code-group
```vue [nanime]
<script setup lang="ts">
const items = ref([1, 2, 3, 4, 5])
</script>

<template>
  <AnimeTransitionGroup
    tag="ul"
    enter-animation="scale"
    leave-animation="scale"
    class="relative"
  >
    <li v-for="item in items" :key="item">{{ item }}</li>
  </AnimeTransitionGroup>
</template>
```

```vue [AnimeJS on its own]
<script setup lang="ts">
import { animate } from 'animejs/animation'

const items = ref([1, 2, 3, 4, 5])

function onEnter(el: Element, done: () => void) {
  animate(el, {
    opacity: [0, 1],
    scale: [0.85, 1],
    duration: 300,
    ease: 'out(3)',
    onComplete: done,
  })
}

function onLeave(el: Element, done: () => void) {
  animate(el, {
    opacity: 0,
    scale: 0.85,
    duration: 200,
    ease: 'in(3)',
    onComplete: done,
  })
}
</script>

<template>
  <TransitionGroup tag="ul" :css="false" @enter="onEnter" @leave="onLeave">
    <li v-for="item in items" :key="item">{{ item }}</li>
  </TransitionGroup>
</template>
```

```vue [@hypernym/nuxt-anime]
<script setup lang="ts">
const { $anime } = useNuxtApp()

const items = ref([1, 2, 3, 4, 5])

function onEnter(el: Element, done: () => void) {
  $anime({
    targets: el,
    opacity: [0, 1],
    scale: [0.85, 1],
    duration: 300,
    easing: 'easeOutCubic',
    complete: done,
  })
}

function onLeave(el: Element, done: () => void) {
  $anime({
    targets: el,
    opacity: 0,
    scale: 0.85,
    duration: 200,
    easing: 'easeInCubic',
    complete: done,
  })
}
</script>

<template>
  <TransitionGroup tag="ul" :css="false" @enter="onEnter" @leave="onLeave">
    <li v-for="item in items" :key="item">{{ item }}</li>
  </TransitionGroup>
</template>
```
::

The AnimeJS and `@hypernym/nuxt-anime` versions use Vue's
`<TransitionGroup>` with `:css="false"`.
Vue animates moves only through a CSS move class, so the other items jump
to their new places.
