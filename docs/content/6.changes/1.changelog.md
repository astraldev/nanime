# Changelog

For the full changelog, see the [GitHub releases](https://github.com/astraldev/nanime/releases){target="_blank"}.

## Unreleased

### Added

- `useAnimeScroll`, wrapping AnimeJS `onScroll()`. It owns the observer's
  lifecycle. Pass it to an animation's `autoplay` and the scroll position
  drives the playhead.
- `keepTime` is a module option. Set `nanime.keepTime` in `nuxt.config` instead
  of repeating it at every call site. It goes through public runtime config, so
  an app-level override or an env var still wins, and a per-call `false` still
  beats a global `true`.
- `useSplitText` exposes `refresh()`, for re-splitting after the element's text
  changes.
- A composable's return value can be passed anywhere AnimeJS accepts an
  instance, such as `autoplay` or `.sync()`. It is recognised by its proxy
  marker, not by the name of the parameter it lands in.
- `#nanime/types` also carries the scroll and remaining SVG types, so neither
  needs an `animejs` import.
- The package ships a `nanime` skill for coding agents, covering the
  composables, the `#nanime/*` aliases, and the failure modes that raise no
  error.

### Fixed

- `useSplitText` returned an empty `methods` object. Property extraction now
  walks the prototype chain and binds, and uses `Object.hasOwn`, so
  `toString` and `valueOf` are no longer skipped.
- `useSplitText` re-splits the element's current text and watches explicit
  sources, which fixes a runaway on mount.
- A timeline emptied itself when its parameters changed. Buffered calls are
  replayed on the rebuild, so it keeps its content.
- A running animation keeps its playhead across a rebuild, since `keepTime` is
  on by default.
- `useAnimate` watched only its target, so a change to `parameters` never
  reached the animation. It watches both now.
- An animation whose parameters carry an instance another composable owns is
  cancelled rather than reverted on rebuild. AnimeJS `Timer.revert()` cascades
  into the linked `ScrollObserver`, which left the replacement bound to a
  reverted one.
- `autoplay` resolved to `null` when the scroll observer did not exist yet, and
  never relinked afterwards.

### Performance

- A rebuild is skipped when the new parameters are shallow-equal to the old
  ones. The comparison costs about 0.06us, against roughly 2.8ms to rebuild at
  200 targets.

### Docs

- Every page rewritten for shorter, plainer sentences.
- Composable pages follow one layout: Usage, Signature, Parameters, Returns,
  Caveats, Type reference, See also.
- Corrected the API claims on those pages. The return is a reactive proxy over
  a `shallowRef`, not a `shallowReactive` wrapper, and reading `progress` in a
  template never re-renders. Three signatures were missing their `options`
  argument. Only chainable methods are buffered before mount. `useAnimatable`
  rebuilds when its target changes, not when its options do.
- Upstream AnimeJS defaults are now taken from the installed package. Several
  were wrong, including `ease`, `splitText` `words`, and every `onScroll`
  threshold.
- Corrected the example pages against their components. Five timelines are
  synced, not four. The drag handle is the absolutely positioned element. The
  scramble target is a `ref`, not a computed.
- Added a [Scroll road trip](/examples/scroll-road-trip) showcase.
- Corrected the skill's claim about ref unwrapping. AnimeJS resolves framework
  refs only in `createScope`'s root parameter, so a `ref` passed as a scroll
  observer's `container` or `target` resolves to nothing and falls back to
  `document.body`.

## v0.0.11...v0.1.12

### Breaking

- Removed the `<ATransitionSlide>`/`<ATransitionScale>` transition components, along with the `components` and `prefix` module options and the `#nanime/components` alias. They broke under `useAnimeLayout`, and maintaining them properly wasn't worth it right now. Nanime is composables-only for the time being, and transition components may return later as a dedicated package once layout handling is sorted out.
- `useAnimeTimeline` and `useDraggable` now return `BufferedProxyReturns<T>` rather than `ProxyReturns<T>`. Methods are no longer typed as possibly `undefined`, so code that used optional chaining still compiles, and code that type-guarded on `undefined` no longer needs to.

### Packaging

- `@vueuse/core` is no longer a dependency at all. The three helpers the runtime used from it (`useMounted`, `tryOnScopeDispose` and `toReactive`) are now in-tree, so installing `nanime` no longer pulls VueUse in.
- `animejs` and `defu` are plain dependencies now, and `vue` is the only peer left. Both are imported at runtime, so nothing has to be installed alongside `nanime` any more.

### Added

- `useDraggable` returns a buffered proxy. Methods called before the instance exists are replayed once it is created, so `draggable.disable()` no longer needs optional chaining.
- `useAnimeTimeline` buffers the whole timer control surface, not just the builder methods. `play`, `pause`, `resume`, `restart`, `reset`, `reverse`, `alternate`, `seek`, `cancel`, `complete`, `init` and `resetTime` join `stretch`, `refresh` and `revert` as chainable calls that are safe before mount.
- New `#nanime/proxies/svg` alias re-exporting `morphTo`, `createMotionPath` and `createDrawable`, plus a `#nanime/proxies` root that re-exports both the text and SVG proxies.
- `#nanime/utils` also exports `animate` and `createTimer` for imperative work outside a composable.
- `#nanime/types` adds `JSAnimation`, `Timer`, `TimerParams`, `TimerOptions`, `DrawableSVGGeometry`, `TextSplitterParams` and `SplitTemplateParams`.
- `animejs/svg` and `animejs/timer` are pre-bundled by the module's Vite config, alongside the modules already listed.

### Fixed

- `.sync()` accepts a composable's return value whether or not the underlying instance is held in a ref. `resolveNanimeInstance` previously assumed a ref and read `.value` off a raw instance.

### Docs

- Added a [Performance](/getting-started/performance) guide covering engine choice, high-frequency updates and split-text cost, and caveats for every composable page.
- Added an [Examples](/examples/introduction) section with four showcase demos, replacing the transition components docs.
- Example demos can be resized horizontally to check narrower widths.

## v0.0.11

- Added `useAnimeTimeline` composable wrapping anime.js `createTimeline()` with Vue ref target normalization, pre-mount command buffering, and timeline syncing.
- Composable returns can now be passed directly to `.sync()`. nanime unwraps them to raw anime.js instances.

## v0.0.9/v0.0.10

- Added `useScrambleText` composable wrapping anime.js `scrambleText()` with reactive text cycling.
- Renamed `useLayout` to `useAnimeLayout`. It stays auto-imported but undocumented and unsupported while its interaction with Vue's DOM management is worked out.
- Broadened `@vueuse/core` peer dep to support v13 and v14.

## v0.0.8

- Integrated Nuxt Studio.
- Added instant play support for calling composables outside `setup()`.
- Renamed animation `options` to `parameters` across all composables.

## v0.0.7

- Added "view on GitHub" links for doc examples.
- Fixed documentation link issues.

## v0.0.5

- Initial release with `useAnimate`, `useWaapiAnimate`, `useAnimatable`, `useSplitText`, and `useDraggable`.
