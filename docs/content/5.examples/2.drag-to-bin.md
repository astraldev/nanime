A list of cards and a bin. Dropping a card on the bin removes it from the
list. The cards below move up to close the gap. You can restore a removed
card.

## What's happening

The card shrinks and slides toward the bin as you drag it closer. Dropped
inside, it fades out. The list closes the gap the card leaves behind. If
you pull it back out before releasing, it returns to its normal size.

## How it's built

The card's movement, and its return trip, both come from
[`useDraggable`](/composables/use-draggable). The card springs back to its
origin on its own when released outside the bin: `snap: [0]` with
`releaseEase: spring({ bounce: 0.2, duration: 500 })` handles the return, so
no release handler is needed.

The shrink runs off [`useAnimatable`](/composables/use-animatable), easing
the card smaller and toward the bin as it gets close. It eases back out if
you pull the card away. Everything else is CSS: the bin's highlight, the
fade on drop, and the list closing the gap all follow from that same "over
the bin" state.

On release, `draggable.stop()` halts the card if it was over the bin. To
restore a binned card later, call `draggable.reset()`.

::note
The distance to the bin only needs measuring once, right when the drag
starts. Nothing else in the list moves until the card is released, so
`useDraggable` skips remeasuring every frame.
::

## Building it yourself

1. Wrap each item in a ghost element that stays in normal flow. This preserves the list position and lets the list reflow when a card is removed.
2. Inside the ghost, position a fixed-size handle absolutely, and size the visible card to fill it. Only the handle is dragged.
3. Call `useDraggable(handle, { onGrab, onUpdate, onRelease })`. In `onGrab`, measure the ghost's rest rect and the bin's rect once, and compute the size delta between them.
4. In `onUpdate`, test whether the handle's centre falls inside the bin's rect, and report that boolean only when it changes.
5. Drive a [`useAnimatable`](/composables/use-animatable) value from `0` to `1` off that boolean, and interpolate width, height, and offset from it in a computed style.
6. Give the draggable `snap: [0]` and a `releaseEase` spring, so a card dropped outside the bin returns on its own.
7. On release, if the boolean was true, stop the draggable and mark the item binned. Collapse the ghost's height and margin with a CSS transition to close the gap.
8. To restore, set the blend value back to `0` and call `draggable.reset()`.
