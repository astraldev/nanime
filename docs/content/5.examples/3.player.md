## Try it

The numbered controls work. The greyed ones fill out the page and do
nothing. There is no audio: the playhead is an AnimeJS animation.

1. **Drag the seek bar.** The time follows the thumb while you drag, and
   playback jumps there when you let go. While playing, the thumb moves
   with the playhead.
2. **Play, pause, skip.** The play button's icon swaps with a small pop.
   The level meters bounce while playing and settle when paused. On a new
   track the cover fades up, the title scrambles into the new name, then
   the artist line fades in.
3. **Drag the volume slider.** The level meters get taller or shorter with
   the volume.
4. **Click a track in the playlist** to play it. The highlight moves to it,
   and the list stays where it is.
5. **Shuffle** the playlist. The rows slide into their new order.

Reset in the title bar stops playback and puts the playlist back in order.

## Built with

- [`useAnimate`](/composables/use-animate): the playhead, as an animation
  of a number
- [`useAnimeTimeline`](/composables/use-anime-timeline): the artist line
  and total time on each track change
- [`useScrambleText`](/composables/use-scramble-text): the track title
- [`useDraggable`](/composables/use-draggable): the seek and volume thumbs
- [`useAnimatable`](/composables/use-animatable): the level meters
- [`<AnimeTransitionGroup>`](/components/transitions): the playlist
  shuffle
- [`<AnimeTransition>`](/components/transitions): the cover crossfade and
  the play and pause icons
- `spring` from [`#nanime/easings`](/composables/utilities), and `shuffle`
  and `random` from [`#nanime/utils`](/composables/utilities)

::collapsible{name="How it's built"}
**Playhead.** There is no audio element. A `usePlayer` composable keeps
`clock = reactive({ time: 0 })` and animates it with
[`useAnimate`](/composables/use-animate): `time` goes from `0` to the
track's length in seconds, over that many seconds, with `ease: 'linear'`
and `autoplay: false`. Play and pause call the animation's `play()` and
`pause()`. Seeking calls `seek()` with the time in milliseconds, which also
works while paused. `onComplete` moves to the next track. The params are a
getter that reads the current track, so a new track rebuilds the animation
with its own length.

**Sliders.** Both sliders are one component. The thumb gets
[`useDraggable`](/composables/use-draggable) with `container` set to the
rail, `y: false` and `velocityMultiplier: 0`, so it stays on the rail and
stops where it is let go instead of sliding on. The rail is the thumb's
width longer than the track it draws, so the thumb's centre lines up with
both ends. The value is the draggable's `x` divided by that range. While
the value changes from outside, for example as the playhead moves,
`setX(value * range, true)` moves the thumb without firing the drag
callbacks. `onDrag` reports the value as it moves and `onRelease` reports
the final one. The seek bar only seeks on release, and shows the dragged
time until then.

**Track change.** The cover is keyed on the track inside an
[`<AnimeTransition>`](/components/transitions). Both covers sit
`absolute inset-0` in the same box, and the transition runs the old one's
leave and the new one's enter together, so they crossfade over 400ms.

[`useScrambleText`](/composables/use-scramble-text) watches the track's
title and scrambles the heading into each new one. The heading renders the
first title with `v-once`, so Vue leaves its text to the scramble after
that. The artist line and the total time keep their elements, so a
[`useAnimeTimeline`](/composables/use-anime-timeline) built once with
`autoplay: false` holds their fades, and a watcher on the track's id calls
`restart()`. They fade in at 150ms and 250ms, so a track change runs in
order rather than all at once.

**Level meters.** Sixteen bars read their heights from one reactive object
animated by [`useAnimatable`](/composables/use-animatable), one property
per bar. While playing, an interval sets each bar to a new `random` height
every 180ms, scaled by the volume. An animatable starts each move from
where the bar is, so the bars never jump. When paused, every bar goes back
to a low resting height.

**Playlist.** The playlist keeps all six tracks in place and marks the
current one, so picking a track only moves the highlight. A queue that
took the picked track out and put the old one back at the end would add a
leave, a move and an enter to every track change. The list is an
[`<AnimeTransitionGroup>`](/components/transitions), and Shuffle replaces
it with a new order that the group moves the rows into over 350ms. The
move has no stagger. The group staggers every element inside it, not only
the rows, so a stagger would make each row's text trail behind its row.
::

small spring overshoot only for things that pop in.

0 }). current is a computed that finds currentId in the playlist.

Playhead: playback = useAnimate(clock, () => ({ time: [0,
current.value.duration], duration: current.value.duration * 1000, ease:
'linear', autoplay: false, onComplete: next })). The getter rebuilds the
animation for each new track. Watch currentId and call playback.seek(0),
then playback.play() if playing. play() and pause() set playing and call
the animation's play() and pause(). seek(fraction) calls
playback.seek(fraction * duration * 1000). next() and previous() step
currentId through the playlist, wrapping at the ends, and previous()
restarts the track instead when more than 3 seconds in. playTrack(track)
sets currentId and plays, or toggles play when it is already current.

draggable = useDraggable(thumb, { container: rail, y: false,
velocityMultiplier: 0, onGrab, onDrag, onRelease, onResize: measure }).

  Inside it, a div keyed on the track id, "absolute inset-0", with the
  track's gradient and icon. Both covers are stacked during the change, so
  they crossfade.
