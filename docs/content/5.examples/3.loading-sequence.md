A terminal-style build log you can run, pause and resume. Pausing stops the
spinner and the step timer together. On resume, the spinner carries on from
the angle it stopped at.

## What's happening

Run starts the log ticking through build steps one at a time, with a
spinner turning next to the status line. Each step's text scrambles through
random characters before settling on the new line. When the last step
finishes, the spinner is replaced by a checkmark that pops in.

## How it's built

Three composables split the work by state.
[`useWaapiAnimate`](/composables/use-waapi-animate) spins the icon off the
main thread so it does not stutter under other work.
[`useScrambleText`](/composables/use-scramble-text) handles the text between
steps, and [`useAnimate`](/composables/use-animate) pops the checkmark in at
the end.

The steps are a plain array of objects, each with its text and an optional
scramble duration. A `setTimeout` chain advances through them. The step's
scramble duration plus a fixed reading pause sets how long to wait before the
next step. Pausing clears that timer, and resuming sets a fresh one so the
current step waits out its full pause again.

The scramble needs no imperative trigger. Its target text is a `ref` that each
step writes to, and the scramble options are a computed built from that `ref`.
`useScrambleText` picks up the change the moment the step advances.

The spinner and the checkmark are each scoped to their state. The spinner
element is in the DOM only while loading and the checkmark only on success.
Both composables are created in `setup()` with a template ref that is still
`null`, and each one attaches when its element appears.

## Building it yourself

1. Define the steps as a plain array, each with its status text and an optional scramble duration.
2. Track state as `'idle' | 'loading' | 'success'`, plus the current step index and status text.
3. Render the spinner only while `state === 'loading'`, and turn it with [`useWaapiAnimate`](/composables/use-waapi-animate) on a linear, looping rotation to 360°.
4. Bind the status line to [`useScrambleText`](/composables/use-scramble-text), with the target text in a `ref` that each step writes to. Changing that text is enough to trigger a new scramble.
5. Advance with a `setTimeout` chain: scramble duration plus a fixed reading pause.
6. Pause by clearing the timer and pausing the spinner instance. Resume by playing it again and setting a fresh timer for the current step's full wait.
7. On the last step, switch to `'success'` and animate a checkmark in with [`useAnimate`](/composables/use-animate).
