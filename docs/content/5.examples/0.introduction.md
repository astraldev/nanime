Each example builds a complete sequence out of `nanime` composables and
utilities. For individual API demos, see the
[composable pages](/composables/introduction).

::u-page-grid
  :::u-page-card{to="/examples/drive" icon="i-ph-hard-drives" title="Drive" variant="soft"}
  #description
  A file manager whose tiles switch layout, filter, sort, and drag into the trash with undo.
  :::

  :::u-page-card{to="/examples/road-trip" icon="i-ph-car-profile" title="Road trip" variant="soft"}
  #description
  A trip planner. Scroll the route to drive the car past each stop, then book it and watch the booking log run.
  :::

  :::u-page-card{to="/examples/player" icon="i-ph-music-notes" title="Player" variant="soft"}
  #description
  A music player whose track changes play a timeline, with draggable seek and volume sliders and a playlist that shuffles.
  :::
::
