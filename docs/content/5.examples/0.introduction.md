Each example builds a complete sequence out of `nanime` composables and
utilities. For individual API demos, see the
[composable pages](/composables/introduction).

::u-page-grid
  :::u-page-card{to="/examples/timeline-storyboard" icon="i-ph-list-numbers" title="Timeline storyboard" variant="soft"}
  #description
  Five independent timelines synced onto one master, with scrub controls.
  :::

  :::u-page-card{to="/examples/drag-to-bin" icon="i-ph-trash" title="Drag to bin" variant="soft"}
  #description
  Drag a card onto the bin, and the list closes the gap behind it.
  :::

  :::u-page-card{to="/examples/loading-sequence" icon="i-ph-spinner-gap" title="Loading sequence" variant="soft"}
  #description
  A build log that runs, pauses and resumes, scrambling its status line between steps.
  :::

  :::u-page-card{to="/examples/text-scatter" icon="i-ph-magnet" title="Text magnet" variant="soft"}
  #description
  Letters near the cursor get pushed away or pulled in, and the mode flips every 5 seconds.
  :::

  :::u-page-card{to="/examples/scroll-road-trip" icon="i-ph-car-profile" title="Scroll road trip" variant="soft"}

  :::
