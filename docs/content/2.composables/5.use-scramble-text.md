The `useScrambleText` composable wraps the [scrambleText](https://animejs.com/documentation/text/scramble-text) utility from AnimeJS, providing a reactive way to animate text with a scramble/reveal effect.

## Type Definition

```ts
function useScrambleText(
  target: AnimeTargets,
  animationOptions?: MaybeRefOrGetter<AnimationParams>,
  scrambleOptions?: MaybeRefOrGetter<ScrambleTextParams>,
): JSAnimation
```

### Arguments

::field-group
  ::field{name="target" type="AnimeTargets" required}
  The element whose text content will be scrambled. Can be a CSS selector, DOM element, Vue template ref, or component.
  ::

  ::field{name="animationOptions" type="MaybeRefOrGetter<AnimationParams>"}
  Standard AnimeJS animation parameters (e.g., `autoplay`, `loop`, `alternate`). These control the animation playback, not the scramble behavior.
  ::

  ::field{name="scrambleOptions" type="MaybeRefOrGetter<ScrambleTextParams>"}
  Options specific to the scramble effect. See the [AnimeJS Scramble Text documentation](https://animejs.com/documentation/text/scrambletext/scrambletext-parameters) for all available options.
  ::
::

## Return Value

Returns a `shallowReactive` object wrapping the AnimeJS animation instance.

::warning
**Do not destructure** the return value. The instance is wrapped in `shallowReactive` to maintain reactivity.
::

```ts
// ❌ Avoid destructuring
const { restart } = useScrambleText(el, {}, { text: 'Hello' })

// ✅ Access methods directly
const animation = useScrambleText(el, {}, { text: 'Hello' })
animation.restart()
```

## API

### Types

```ts
type AnimeTargets = TargetsParam | MaybeElementRef | MaybeElementRef[]
```

See [AnimeJS Scramble Text documentation](https://animejs.com/documentation/text/scramble-text) for the full `ScrambleTextParams` type.
