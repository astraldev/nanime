`useScrambleText` wraps the [scrambleText](https://animejs.com/documentation/text/scrambletext){target="_blank"}
utility from AnimeJS. It animates an element's text content through random
characters before settling on the final string.

Both animation and scramble parameter objects accept reactive inputs. Changing
either configuration rebuilds the underlying animation. By default it
restarts. Set `keepTime: true` to carry the playhead over so the scramble
continues instead.

## Usage

## Signature

```ts
function useScrambleText(
  target: AnimeTargets,
  animationOptions?: MaybeRefOrGetter<ScrambleAnimationParams>,
  scrambleOptions?: MaybeRefOrGetter<ScrambleTextParams>,
  options?: NanimeInstanceOptions
): JSAnimation
```

## Parameters

::field-group
  :::field{name="target" type="AnimeTargets" required}
  Target element whose text is scrambled. Accepts CSS selectors, DOM elements,
  and template refs.
  :::

  :::field{name="animationOptions" type="MaybeRefOrGetter<ScrambleAnimationParams>"}
  Playback and callbacks, such as `loop` or `onComplete`. Accepts a plain
  object, a `ref` or a getter, and the animation rebuilds when it changes.
  Timing goes in `scrambleOptions`. See the
  [AnimeJS animation documentation](https://animejs.com/documentation/animation){target="_blank"}
  for the options.
  :::

  :::field{name="scrambleOptions" type="MaybeRefOrGetter<ScrambleTextParams>"}
  What to scramble to and when, such as `text`, `chars`, `duration`, `delay`
  and `ease`. Accepts a plain object, a `ref` or a getter, and a new `text`
  scrambles to the new string. See the
  [AnimeJS scrambleText documentation](https://animejs.com/documentation/text/scrambletext){target="_blank"}
  for the options.
  :::

  :::field{name="options" type="NanimeInstanceOptions"}
  How the animation behaves when it rebuilds.

  | Option | Type | Default |
  | :--- | :--- | :--- |
  | `keepTime` | `boolean`{lang="ts-type"} | `false` |
  :::
::

## Returns

Returns a reactive proxy around the AnimeJS `JSAnimation`{lang="ts-type"}.
Its methods and properties are in the
[AnimeJS animation documentation](https://animejs.com/documentation/animation){target="_blank"}.
Call methods on the returned object, as in `animation.restart()`, because
a [destructured method throws](#do-not-destructure-the-returned-instance).
`progress` [doesn't update a template](#properties-do-not-update-templates)
either.

## Caveats

### Timing belongs in scrambleOptions

```ts
// wrong: a type error, and AnimeJS would ignore them
useScrambleText(el, { duration: 2000, delay: 500 }, { text: 'Hello' })

// right
useScrambleText(el, {}, { text: 'Hello', duration: 2000, delay: 500 })
```

The tween from AnimeJS `scrambleText()` sets its own `duration`, `delay` and
`ease`, which replace the ones in `animationOptions`, so
`ScrambleAnimationParams`{lang="ts-type"} rejects them. Without them, the
duration comes from the text length and `revealRate`.

### Do not destructure the returned instance

```ts
// wrong: restart() throws when called
const { restart } = useScrambleText(el, {}, { text: 'Hello' })

// right
const animation = useScrambleText(el, {}, { text: 'Hello' })
animation.restart()
```

The proxy hands back methods without their instance, so a destructured
`restart()` runs with no `this` and throws. A destructured property such as
`progress` is a copy of the value at that moment. Keep the returned object
and call methods on it.

### Properties do not update templates

```ts
// wrong: progress never updates inside a template interpolation
// <p>{{ animation.progress }}</p>

// right: update a ref inside onUpdate
const progress = ref(0)
const animation = useScrambleText(el, {
  onUpdate: self => progress.value = self.progress,
}, { text: 'Hello' })
```

Interpolating properties like `progress` in a template displays only their
initial value. AnimeJS updates them outside Vue's reactivity tracking, so
nothing triggers a re-render. Assign the current value to a
`ref`{lang="ts-type"} inside the `onUpdate` callback to drive reactive
template elements.
