`useScrambleText` wraps the [scrambleText](https://animejs.com/documentation/text/scrambletext){target="_blank"}
utility from AnimeJS. It animates an element's text content through random
characters before settling on the final string.

Both animation and scramble parameter objects accept reactive inputs. Changing
either configuration automatically triggers a rebuild and replays the scramble
transition.

## Usage

:render-code-block-preview{src="examples/composables/ScrambleTextDemo.vue"}

## Signature

```ts
function useScrambleText(
  target: AnimeTargets,
  animationOptions?: MaybeRefOrGetter<AnimationParams>,
  scrambleOptions?: MaybeRefOrGetter<ScrambleTextParams>,
  options?: NanimeInstanceOptions
): JSAnimation
```

## Parameters

::field-group
  :::field{name="target" type="AnimeTargets" required}
  Target element whose text is scrambled. Accepts CSS selectors, DOM elements,
  and template refs.
  :::

  :::field{name="animationOptions" type="MaybeRefOrGetter<AnimationParams>"}
  Playback settings controlling the tween duration, easing, and loops.

  | Option | Type | Default |
  | :--- | :--- | :--- |
  | `duration` | `number`{lang="ts-type"} | `1000` |
  | `ease` | `EasingParam`{lang="ts-type"} | `'out(2)'` |
  :::

  :::field{name="scrambleOptions" type="MaybeRefOrGetter<ScrambleTextParams>"}
  Scramble parameters defining text content and character randomization.

  | Option | Type | Default |
  | :--- | :--- | :--- |
  | `text` | `string \| ((target: Target, index: number, targets: TargetsArray) => string)`{lang="ts-type"} | The target's existing text |
  | `chars` | `string \| ((target: Target, index: number, targets: TargetsArray) => string)`{lang="ts-type"} | `'a-zA-Z0-9!%#_'` |
  :::

  :::field{name="options" type="NanimeInstanceOptions"}
  Instance options controlling rebuild and lifecycle behaviour.

  | Option | Type | Default |
  | :--- | :--- | :--- |
  | `keepTime` | `boolean`{lang="ts-type"} | `true` |
  :::
::

## Returns

Returns a reactive proxy around the AnimeJS `JSAnimation`{lang="ts-type"}
instance.

| Member | Type | Notes |
| :--- | :--- | :--- |
| `play()` | `() => this`{lang="ts-type"} | Starts or resumes playback. Destructuring-unsafe; see the [destructuring caveat](#do-not-destructure-the-returned-instance). |
| `pause()` | `() => this`{lang="ts-type"} | Pauses playback. |
| `restart()` | `() => this`{lang="ts-type"} | Restarts the scramble sequence from the beginning. |
| `revert()` | `() => this`{lang="ts-type"} | Reverts text to its pre-animation content. |
| `progress` | `number`{lang="ts-type"} | Current animation progress between `0` and `1`. Does not update templates; see the [template reactivity caveat](#progress-and-playback-properties-do-not-update-templates). |
| `paused` | `boolean`{lang="ts-type"} | Whether the animation is currently paused. |

::warning
Internal animation properties like `progress` do not trigger Vue template
re-renders. See the [template reactivity caveat](#progress-and-playback-properties-do-not-update-templates).
::

## Caveats

### Do not destructure the returned instance

```ts
// wrong: copies methods once, losing the link on rebuild
const { restart } = useScrambleText(el, {}, { text: 'Hello' })

// right: calls restart on the active proxy
const animation = useScrambleText(el, {}, { text: 'Hello' })
animation.restart()
```

Destructuring properties or methods off the returned proxy binds them to the
initial instance. When reactive parameters change and rebuild the animation,
destructured functions continue targeting the discarded instance. Retain the
proxy object and invoke methods directly on it.

### Progress and playback properties do not update templates

```ts
// wrong: progress never updates inside a template interpolation
// <p>{{ animation.progress }}</p>

// right: update a ref inside onUpdate
const progress = ref(0)
const animation = useScrambleText(el, {
  onUpdate: self => progress.value = self.progress,
}, { text: 'Hello' })
```

Interpolating properties like `progress` in a template displays only their
initial value. AnimeJS updates internal animation state during its animation
loop on the main thread outside Vue's reactivity tracking. Assign the current
value to a `ref`{lang="ts-type"} inside the `onUpdate` callback to drive
reactive template elements.
