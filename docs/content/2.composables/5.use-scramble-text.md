The `useScrambleText` composable wraps the [scrambleText](https://animejs.com/documentation/text/scrambletext){target="_blank"} utility from AnimeJS, providing a reactive way to animate text with a scramble/reveal effect.

## Arguments

::field-group
  :::field{required name="target" type="AnimeTargets"}
  The element whose text content will be scrambled. Can be a CSS selector, DOM element, Vue template ref, or component.
  :::

  :::field{name="animationOptions" type="MaybeRefOrGetter<AnimationParams>"}
  Standard AnimeJS animation parameters (e.g., `autoplay`, `loop`, `alternate`). These control the animation playback, not the scramble behavior.
  :::

  :::field{name="scrambleOptions" type="MaybeRefOrGetter<ScrambleTextParams>"}
  Options specific to the scramble effect. See the [AnimeJS Scramble Text documentation](https://animejs.com/documentation/text/scrambletext/scrambletext-parameters){target="_blank"} for all available options.
  :::
::

## Return Value

Returns a `shallowReactive` object wrapping the AnimeJS animation instance.

## API

### Types

```ts
function useScrambleText(
  target: AnimeTargets,
  animationOptions?: MaybeRefOrGetter<AnimationParams>,
  scrambleOptions?: MaybeRefOrGetter<ScrambleTextParams>,
): JSAnimation
```

::collapsible{name="Type aliases"}
```ts
type AnimeTargets = TargetsParam | MaybeElementRef | MaybeElementRef[]
```
::

See [AnimeJS Scramble Text documentation](https://animejs.com/documentation/text/scrambletext/scrambletext-parameters){target="_blank"} for the full `ScrambleTextParams` type.

## Caveats

- Don't destructure the return value. The instance is wrapped in `shallowReactive`, and destructuring copies its values out once, disconnecting them from the instance.

```ts
// loses the connection to the instance
const { restart } = useScrambleText(el, {}, { text: 'Hello' })

// keeps it
const animation = useScrambleText(el, {}, { text: 'Hello' })
animation.restart()
```

::tip
Call `useScrambleText` synchronously in `setup()` for it to react to `animationOptions` and `scrambleOptions`
changes. Called from `onMounted`, a watcher, or a handler, it runs in
[instant mode](/composables/introduction#instant-play): the animation is
created once and both option objects are read only that first time.
::
