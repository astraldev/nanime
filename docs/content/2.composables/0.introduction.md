One composable per [AnimeJS](https://animejs.com/){target="_blank"} API,
plus the experimental `useWaapiTimeline` on the browser's Web Animations
API, each with a live demo. For enter, leave and list animations, see the
[transition components](/components/transition).

The composables are auto-imported, so you can call them without an import.
The one exception is the experimental `useWaapiTimeline`, which you import
from `#nanime/experimental`.

## Choosing a composable

| Composable | Use it to | Outside `setup()` | Calls before mount | `rebuild` |
| :--- | :--- | :--- | :--- | :--- |
| [`useAnimate`](/composables/use-animate) | Animate CSS properties, transforms, SVG attributes and JS objects with [`animate()`](https://animejs.com/documentation/animation){target="_blank"} | Yes | Ignored | `'keepTime'`, `'keepValue'` |
| [`useWaapiAnimate`](/composables/use-waapi-animate) | Animate `transform` and `opacity` off the main thread with [`waapi.animate()`](https://animejs.com/documentation/web-animation-api){target="_blank"} | Yes | Ignored | No |
| [`useAnimatable`](/composables/use-animatable) | Tween a value that changes many times a second, such as a cursor position, with [`createAnimatable()`](https://animejs.com/documentation/animatable){target="_blank"} | Yes | Throws | No |
| [`useSplitText`](/composables/use-split-text) | Split text into lines, words and characters with [`splitText()`](https://animejs.com/documentation/text){target="_blank"} | No | Not applicable | No |
| [`useScrambleText`](/composables/use-scramble-text) | Scramble an element's text and reveal a new string with [`scrambleText()`](https://animejs.com/documentation/text/scrambletext){target="_blank"} | Yes | Ignored | `'keepTime'` |
| [`useAnimeTimeline`](/composables/use-anime-timeline) | Run several animations on one clock with [`createTimeline()`](https://animejs.com/documentation/timeline){target="_blank"} | Yes | Queued | `'keepTime'` |
| [`useWaapiTimeline`](/composables/use-waapi-timeline) (experimental) | Run positioned CSS tweens on the browser's own [Web Animations](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API){target="_blank"} clock | Yes | Queued | No |
| [`useDraggable`](/composables/use-draggable) | Make an element draggable, with snapping and bounds, using [`createDraggable()`](https://animejs.com/documentation/draggable){target="_blank"} | No | Queued | No |
| [`useAnimeScroll`](/composables/use-anime-scroll) | Drive an animation from scroll position with [`onScroll()`](https://animejs.com/documentation/scroll){target="_blank"} | No | Queued | No |
| [`useAnimeLayout`](/composables/use-anime-layout) | Animate position and size changes of a container's children with [`createLayout()`](https://animejs.com/documentation/layout){target="_blank"} | No | Queued | No |

The two badges on a composable page mean:

::nuxt-link{to="/composables/composable-lifecycle#instant-play"}
:badge{icon="mage:zap-fill" label="Instant play" size="md" variant="soft"}
::
means the composable also works outside `setup()`, for example in a click
handler.

::nuxt-link{to="/composables/composable-lifecycle#buffered"}
:badge{icon="ph:stack" label="Buffered" size="md" variant="soft"}
::
means methods called in `setup()` are queued until the component mounts.

[Composable lifecycle](/composables/composable-lifecycle) covers the build and
rebuild rules. [Utilities](/composables/utilities) covers the helpers that
go inside composable parameters.

When [reduced motion](/guides/accessibility) is on, the composables jump to
their end state. `useDraggable` and `useAnimeScroll` are not affected,
because the visitor moves them.
