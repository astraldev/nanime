Import these from the `#nanime/*` aliases in a Nuxt app. A Vue app without
Nuxt imports the same helpers from `nanime/vue`, as
[Vue without Nuxt](/guides/vue) shows. AnimeJS documents each one.

| Import path            | Exports                                             | AnimeJS docs                                                                   |
| :--------------------- | :-------------------------------------------------- | :----------------------------------------------------------------------------- |
| `#nanime/easings`      | `eases`, `cubicBezier`, `linear`, `irregular`, `steps`, `spring`, `createSpring` | [Easings](https://animejs.com/documentation/easings){target="_blank"}          |
| `#nanime/utils`        | `stagger`, `snap`, `round`, `random`, `randomPick`, `shuffle`, `lerp`, `clamp`, `wrap`, `keepTime`, `sync`, `get`, `set`, `remove`, `animate`, `createTimer` and the rest of `animejs/utils` | [Utilities](https://animejs.com/documentation/utilities){target="_blank"}      |
| `#nanime/composables`  | Every composable and `provideAnimeDefaults()`. Use it when `composables: false` | None                                                                           |
| `#nanime/types`        | The parameter and instance types, such as `AnimationParams`, `AnimeScrollParams` and `NanimeInstanceOptions` | None                                                                           |
| `#nanime/proxies/text` | `scrambleText`                                      | [Text](https://animejs.com/documentation/text){target="_blank"}                |
| `#nanime/proxies/svg`  | `morphTo`, `createMotionPath`, `createDrawable`     | [SVG](https://animejs.com/documentation/svg){target="_blank"}                  |
| `#nanime/proxies`      | Everything in `/text` and `/svg`                    |                                                                                |

`animate` and `createTimer` are the plain AnimeJS functions, not reactive.
Use [`useAnimate`](/composables/use-animate) when a Vue component needs
reactivity.

`stagger` works with `useAnimate`, `useWaapiAnimate` and the timeline's
`add()`. `scrambleText`, used as an animated value, works with `useAnimate`
and `useAnimeTimeline` only.

## Create `stagger()` inside a getter when items can be added

:render-code-block-preview{src="examples/composables/StaggerGetterDemo.vue"}

AnimeJS `stagger()` works out each item's step the first time it runs and
keeps them. Adding an item rebuilds the animation with the same
parameters, so the new item gets the first item's step. A getter creates a
fresh stagger on each rebuild, and `rebuild: 'keepTime'` keeps the others
from restarting. `useWaapiAnimate` and the timeline's `add()` behave the same
way.

## Use proxies inside animation parameters

:render-code-block-preview{src="examples/composables/ScrambleProxyDemo.vue"}

`scrambleText()` returns a value you set as `innerHTML`. The animation then
applies it. The helpers in `#nanime/proxies/*` all work this way. This is a
different meaning from the reactive object a composable returns.

Use `scrambleText` when the scramble is one step in a sequence.
To scramble an element whenever a text `ref` changes, use
[`useScrambleText`](/composables/use-scramble-text).
