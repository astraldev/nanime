Import AnimeJS helpers from the `#nanime/*` paths. A Vue app without Nuxt
imports them from `nanime/vue`, as [Vue without Nuxt](/guides/vue) shows.

| Import from | Exports | AnimeJS docs |
| :--- | :--- | :--- |
| `#nanime/easings` | `eases`, `cubicBezier`, `steps`, `spring` and the rest of `animejs/easings` | [Easings](https://animejs.com/documentation/easings){target="_blank"} |
| `#nanime/utils` | `stagger`, `random`, `clamp`, `set` and the rest of `animejs/utils` | [Utilities](https://animejs.com/documentation/utilities){target="_blank"} |
| `#nanime/proxies/text` | `scrambleText` | [Text](https://animejs.com/documentation/text){target="_blank"} |
| `#nanime/proxies/svg` | `createDrawable`, `createMotionPath`, `morphTo` | [SVG](https://animejs.com/documentation/svg){target="_blank"} |

Types such as `AnimationParams` come from `#nanime/types`.

## Stagger a list that can grow

:render-code-block-preview{src="examples/composables/StaggerGetterDemo.vue"}

`stagger()` saves one delay per item the first time it runs. `hop()` passes
the same `stagger()` to every rebuild, so an added item gets no delay and
moves with the first one. `hop` is a getter, so each rebuild gets a new
`stagger()`.

## Use proxies inside animation parameters

:render-code-block-preview{src="examples/composables/ScrambleProxyDemo.vue"}

`scrambleText()` returns a value for `innerHTML`, and the animation scrambles
the text toward it. It works in `useAnimate` and `useAnimeTimeline`. To
scramble whenever a text `ref` changes, use
[`useScrambleText`](/composables/use-scramble-text).
