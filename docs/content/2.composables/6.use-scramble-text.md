`useScrambleText` wraps [`scrambleText()`](https://animejs.com/documentation/text/scrambletext)
from AnimeJS. It rebuilds the animation when `target`, `animationOptions` or
`scrambleOptions` changes, and reverts it when the component unmounts.

## API

```ts
function useScrambleText(
  target: AnimeTargets,
  animationOptions?: MaybeRefOrGetter<ScrambleAnimationParams>,
  scrambleOptions?: MaybeRefOrGetter<ScrambleTextParams>,
  options?: NanimeInstanceOptions
): JSAnimation
```

::field-group
  :::field{name="target" type="AnimeTargets" required}
  Accepts everything AnimeJS accepts, plus template refs and component
  refs. A plain object [must be reactive](/composables/how-composables-run#plain-object-targets-must-be-reactive).
  :::

  :::field{name="animationOptions" type="MaybeRefOrGetter<ScrambleAnimationParams>"}
  Playback and callbacks, such as `loop` or `onComplete`. Accepts a plain
  object, a `ref` or a getter, and the animation rebuilds when it changes.
  Timing goes in `scrambleOptions`. See the
  [AnimeJS animation documentation](https://animejs.com/documentation/animation)
  for the options.
  :::

  :::field{name="scrambleOptions" type="MaybeRefOrGetter<ScrambleTextParams>"}
  What to scramble to and when, such as `text`, `chars`, `duration`, `delay`
  and `ease`. Accepts a plain object, a `ref` or a getter, and a new `text`
  scrambles to the new string. See the
  [AnimeJS scrambleText documentation](https://animejs.com/documentation/text/scrambletext)
  for the options.
  :::

  :::field{name="options" type="NanimeInstanceOptions"}
  Set `keepTime: true` so a rebuild continues from the current playhead.
  The default comes from [Configuration](/guides/configuration#set-module-options)
  and is `false` unless you set it.
  :::
::

Returns the AnimeJS `JSAnimation`{lang="ts-type"}. Call methods on the
returned object, as in `animation.restart()`, because
[a destructured method throws](/composables/how-composables-run#do-not-destructure-the-returned-instance).
Properties such as `progress`[do not update a template](/composables/how-composables-run#properties-do-not-update-templates).

## Avoid common mistakes

### Timing belongs in scrambleOptions

```ts
// wrong: a type error, and AnimeJS would ignore them
useScrambleText(el, { duration: 2000, delay: 500 }, { text: 'Hello' })

// right
useScrambleText(el, {}, { text: 'Hello', duration: 2000, delay: 500 })
```

The tween from AnimeJS `scrambleText()` sets its own `duration`, `delay` and
`ease`, which replace the ones in `animationOptions`, so
`ScrambleAnimationParams`{lang="ts-type"} rejects them. Without them, the
duration comes from the text length and `revealRate`.
