`useAnimeTimeline` wraps the [createTimeline](https://animejs.com/documentation/timeline){target="_blank"}
function from AnimeJS. It synchronizes multiple animations along a shared clock
so you can play, pause, seek, and reverse complex sequences as a single unit.

Calls made before mount are buffered and replayed once the component mounts.
Methods accept Vue template refs, component refs, and reactive targets alongside
CSS selector strings.

## Signature

```ts
function useAnimeTimeline(
  parameters?: MaybeRefOrGetter<TimelineParams>,
  options?: NanimeInstanceOptions
): BufferedProxyReturns<Timeline>
```

## Returns

Returns a buffered proxy around the AnimeJS `Timeline`{lang="ts-type"}
instance.

`nanime` buffers every method call made before the timeline exists. The
content methods below (`add` through `stretch`) also replay on every later
rebuild, so the sequence they built stays in place when `parameters`
changes. The remaining methods run once and are not replayed.

| Member | Type | Notes |
| :--- | :--- | :--- |
| `add(targets, params, position?)` | `(targets: TargetsParam, params: AnimationParams, position?: TimelinePosition) => this`{lang="ts-type"} | Adds an animation to the sequence. Normalizes template refs automatically. |
| `set(targets, params, position?)` | `(targets: TargetsParam, params: AnimationParams, position?: TimelinePosition) => this`{lang="ts-type"} | Sets properties at a specified timeline position. |
| `remove(targets, propertyName?)` | `(targets: TargetsParam, propertyName?: string) => this`{lang="ts-type"} | Removes targets, or one property on them, from the timeline. |
| `label(name, position?)` | `(name: string, position?: TimelinePosition) => this`{lang="ts-type"} | Names a position in the timeline for reuse in later position arguments. |
| `call(callback, position?)` | `(callback: (timer: Timer) => void, position?: TimelinePosition) => this`{lang="ts-type"} | Executes a callback function at a timeline position. |
| `sync(animation, position?)` | `(animation: Tickable \| WAAPIAnimation, position?: TimelinePosition) => this`{lang="ts-type"} | Synchronizes another composable animation to this timeline's clock. |
| `stretch(newDuration)` | `(newDuration: number) => this`{lang="ts-type"} | Scales every child's timing to fit a new total duration. |

The rest are the standard `Timer`/`Timeline` playback controls, unchanged from
AnimeJS: `play`, `pause`, `resume`, `restart`, `reset`, `reverse`,
`alternate`, `seek`, `cancel`, `complete`, `init`, `resetTime`, `refresh`,
and `revert`. All are buffered before mount, but run once rather than
replaying on rebuild.

## Caveats

### Non-chainable properties return undefined before mount

```ts
// wrong: currentTime is undefined before mount
const tl = useAnimeTimeline()
console.log(tl.currentTime) // undefined

// right: read timeline properties after mount
onMounted(() => {
  console.log(tl.currentTime)
})
```

The underlying `Timeline` instance is created after mount, or immediately
in [Instant mode](/composables/introduction#instant-play). Chainable
methods such as `add()`, `play()`, and `pause()` buffer safely before
that and replay in sequence, but non-chainable property reads return
`undefined` until the timeline instance exists. Access inspection properties
after mount.
