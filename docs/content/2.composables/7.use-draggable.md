`useDraggable` wraps [`createDraggable()`](https://animejs.com/documentation/draggable)
from AnimeJS. It rebuilds the draggable when `target` or `trigger` points
to a different element, and keeps it disabled across a rebuild if it was.
A new `container` keeps the current position. It reverts the draggable
when the component unmounts.

## API

```ts
function useDraggable(
  target: DraggableTypes['target'],
  options?: DraggableOptions
): BufferedProxyReturns<Draggable>
```

::field-group
  :::field{name="target" type="DraggableTypes['target']" required}
  The DOM element to make draggable. Accepts CSS selectors, DOM elements, and
  template refs. Keep CSS transitions off its `transform`, since AnimeJS
  writes it on every frame of a drag.
  :::

  :::field{name="options" type="DraggableOptions"}
  See the
  [AnimeJS draggable documentation](https://animejs.com/documentation/draggable)
  for the options. Passed options are merged one at a time over the
  [configured defaults](/guides/defaults#set-app-wide-defaults),
  which leave out `trigger` and `container` because each names a single
  element.

    ::::note
    `trigger` and `container` also accept template refs and component refs.
    `snap` (also inside `x` and `y`), `dragSpeed`, `scrollSpeed`,
    `scrollThreshold`, `containerPadding`, `containerFriction`, `minVelocity`,
    `maxVelocity` and `velocityMultiplier` also accept a `ref`, and a change
    updates the draggable in place.
    ::::
  :::
::

Returns a buffered proxy around the AnimeJS `Draggable`{lang="ts-type"}.
Methods such as `disable()` run once the draggable exists, so they can be
called from `setup()`. Read properties such as `x` and `y` [after mount](/composables/composable-lifecycle#read-properties-after-mount).
