The `useDraggable` composable wraps the [createDraggable](https://animejs.com/documentation/draggable){target="_blank"} function from AnimeJS.

## Arguments

::field-group
  :::field{required name="target" type="DraggableTypes['target']"}
  The element(s) to make draggable. Supports CSS selectors, DOM elements, or template refs.
  :::

  :::field{name="options" type="DraggableOptions"}
  Configuration for dragging behavior. Highly reactive, supporting Vue refs and getters for most properties.
  :::
::

## Return Value

Returns a `ProxyReturns<Draggable>`{lang="ts-type"} object. This is a reactive proxy that wraps the AnimeJS `Draggable` instance.

## API

### Types

```ts
function useDraggable(
  target: DraggableTypes["target"],
  options?: DraggableOptions
): ProxyReturns<Draggable>
```

```ts
type DraggableTargets = DOMTargetSelector | MaybeElementRef<HTMLElement | SVGElement | VueInstance | null> | null | undefined;
type DraggableTargetContainer = DraggableParams["container"] | MaybeElementRef<HTMLElement | VueInstance | null> | null | undefined;
type DraggableTargetTrigger = DraggableParams["trigger"] | DraggableTargets;

type DraggableTypes = {
  target: DraggableTargets;
  trigger: DraggableTargetTrigger;
  container: DraggableTargetContainer;
}

type DraggableOptions = MakeRefable<Omit<DraggableParams, 'trigger' | 'container' | 'x' | 'y'> & {
  trigger?: DraggableTypes["trigger"]
  container?: DraggableTypes["container"]
  x?: boolean | Prettify<MakeRefable<DraggableAxisParam, "snap", Draggable>>
  y?: boolean | Prettify<MakeRefable<DraggableAxisParam, "snap", Draggable>>
}, RefableProps, Draggable>
```

See [AnimeJS Draggable documentation](https://animejs.com/documentation/draggable){target="_blank"} for more details.

## Notes

::caution
Because the draggable instance can be initialized after the component is mounted and only when the target is found,
properties and methods on the returned object may be `undefined` until the initialization is complete.
Always use optional chaining or check for existence before calling methods!
::

```ts
const draggable = useDraggable('.square');

// ✅ Correct
const disable = () => draggable.disable?.();

// ❌ Wrong
const disable = () => draggable.disable();
```

::caution
Never apply CSS transitions to the `transform` property on a draggable element.
Because `useDraggable` writes inline `transform` values every frame, a transition on
`transform` makes dragging feel laggy. Transition other properties instead, or move
the visual change onto a child element so the two never share a property.
::

::caution
`x` and `y` report the element's current `translateX` / `translateY`, parsed from
the DOM — they are **not** guaranteed to start at `0` on a fresh grab. To work with
a true delta, record them in `onGrab` and subtract:

```ts
let origin = { x: 0, y: 0 }

useDraggable(target, {
  onGrab: self => origin = { x: self.x, y: self.y },
  onUpdate: self => moved(self.x - origin.x, self.y - origin.y),
})
```
::

::note
Resizing a draggable element — including via the standalone CSS `scale` property —
trips the `ResizeObserver` AnimeJS attaches to it and schedules a refresh. Prefer
animating a child element when the drag target itself does not need to change size.
::
