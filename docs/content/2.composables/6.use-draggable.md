`useDraggable` wraps the [createDraggable](https://animejs.com/documentation/draggable){target="_blank"}
function from AnimeJS. It makes DOM elements draggable with support for boundary
constraints, coordinate snapping, axis locking, and release momentum.

Calling chainable methods before mount buffers the calls and executes them as
soon as the target element and controller are initialized.

## Usage

:render-code-block-preview{src="examples/composables/DraggableDemo.vue"}

## Signature

```ts
function useDraggable(
  target: DraggableTypes['target'],
  options?: DraggableOptions
): BufferedProxyReturns<Draggable>
```

## Parameters

::field-group
  :::field{name="target" type="DraggableTypes['target']" required}
  The DOM element to make draggable. Accepts CSS selectors, DOM elements, and
  template refs.
  :::

  :::field{name="options" type="DraggableOptions"}
  Drag configuration including boundaries, snapping, and callbacks. Properties
  accept Vue refs and getter functions.

  | Option | Type | Default |
  | :--- | :--- | :--- |
  | `container` | `DraggableTypes['container']`{lang="ts-type"} | `document.body` |
  | `trigger` | `DraggableTypes['trigger']`{lang="ts-type"} | `target` |
  | `dragSpeed` | `MaybeRefOrGetter<number>`{lang="ts-type"} | `1` |
  | `snap` | `MaybeRefOrGetter<number \| number[]>`{lang="ts-type"} | |
  :::
::

## Returns

Returns a buffered proxy around the AnimeJS `Draggable`{lang="ts-type"}
instance, so every method and property it has is available on it. See the
[AnimeJS draggable documentation](https://animejs.com/documentation/draggable){target="_blank"}
for the full surface. Methods (`enable`, `disable`, `reset`, `revert`,
`stop`, `setX`, `setY`, and the rest) are buffered before mount and replay
once the instance exists. Properties, including `x` and `y`, return
`undefined` before mount. See the
[pre-mount properties caveat](#non-chainable-properties-return-undefined-before-mount).

## Caveats

### Non-chainable properties return undefined before mount

```ts
// wrong: reading position before mount returns undefined
const draggable = useDraggable('.card')
console.log(draggable.x) // undefined

// right: read coordinates after mount or inside interaction callbacks
onMounted(() => {
  console.log(draggable.x)
})
```

The underlying `Draggable` instance is constructed after the component mounts
and resolves its target element. Chainable methods buffer safely before mount,
but property reads and non-chainable helper methods return `undefined` until the
instance exists. Access coordinates inside lifecycle hooks or callbacks such as
`onDrag`.

### Never apply CSS transitions to transform

```vue
<!-- wrong: CSS transition conflicts with per-frame transform writes -->
<div class="transition-transform duration-300" ref="card" />

<!-- right: apply transitions only to non-dragged child elements -->
<div ref="card">
  <div class="transition-opacity duration-300" />
</div>
```

The draggable engine writes inline `transform` styles on every frame during
drag interactions. Adding a CSS transition to `transform` causes the browser to
interpolate between consecutive engine writes, producing severe motion lag and
stutter. Move CSS transitions to child elements or animate properties other than
`transform`.

## Type reference

::collapsible{name="Types"}
```ts
type DraggableTargets = DOMTargetSelector | MaybeElementRef<HTMLElement | SVGElement | VueInstance | null> | null | undefined
type DraggableTargetContainer = DraggableParams['container'] | MaybeElementRef<HTMLElement | VueInstance | null> | null | undefined
type DraggableTargetTrigger = DraggableParams['trigger'] | DraggableTargets

type DraggableTypes = {
  target: DraggableTargets
  trigger: DraggableTargetTrigger
  container: DraggableTargetContainer
}

type DraggableOptions = MakeRefable<Omit<DraggableParams, 'trigger' | 'container' | 'x' | 'y'> & {
  trigger?: DraggableTypes['trigger']
  container?: DraggableTypes['container']
  x?: boolean | Prettify<MakeRefable<DraggableAxisParam, 'snap', Draggable>>
  y?: boolean | Prettify<MakeRefable<DraggableAxisParam, 'snap', Draggable>>
}, RefableProps, Draggable>

type BufferedProxyReturns<T> = Exclude<UnwrapNestedRefs<T>, null | undefined>
```
::
