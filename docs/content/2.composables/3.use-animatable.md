The `useAnimatable` composable wraps the [createAnimatable](https://animejs.com/documentation/animatable) function from AnimeJS.

> Efficiently animates target properties, making it an ideal replacement for `animate()` 
> and `utils.set()` in situations where values change frequently,
> such as cursor events or animation loops.

## Arguments

::field-group
  :::field{required name="target" type="AnimeTargets"}
  The reactive object or array of objects to animate.
  :::

  :::field{name="options" type="MaybeRefOrGetter<AnimatableParams>"}
  See [AnimeJS Animatable Properties](https://animejs.com/documentation/animatable/animatable-settings).
  :::
::

## Return Value

Returns a `shallowReactive` object wrapping the AnimeJS `AnimatableObject` instance.

## API

### Types

```ts
function useAnimatable(
  target: AnimeTargets,
  options?: MaybeRefOrGetter<AnimatableParams>
): AnimatableObject
```

```ts
type AnimeTargets = TargetsParam | MaybeElementRef | MaybeElementRef[]
```

See [AnimeJS Animatable documentation](https://animejs.com/documentation/animatable) for more details.

## Notes

::warning
**Do not destructure** the return value. The instance is wrapped in `shallowReactive` to maintain reactivity. Destructuring will break the connection to the underlying AnimeJS instance updates.
::

```ts
// ❌ Avoid destructuring
const { revert } = useAnimatable(obj, { ... })

// ✅ Access methods directly
const animatable = useAnimatable(obj, { ... })
animatable.revert()
```
