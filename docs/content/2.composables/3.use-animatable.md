`useAnimatable` wraps the [createAnimatable](https://animejs.com/documentation/animatable){target="_blank"}
function from AnimeJS. It creates an animatable controller and exposes each
animated property as a getter and setter function.

When you pass a new value to a property setter, the controller smoothly tweens
towards that value from its current position without cancelling or rebuilding the
animation instance.

## Usage

:render-code-block-preview{src="examples/composables/AnimatableDemo.vue"}

## Signature

```ts
function useAnimatable(
  target: AnimeTargets,
  options?: MaybeRefOrGetter<AnimatableParams>
): AnimatableObject
```

## Parameters

::field-group
  :::field{name="target" type="AnimeTargets" required}
  Target DOM element, template ref, or reactive JavaScript object.
  :::

  :::field{name="options" type="MaybeRefOrGetter<AnimatableParams>"}
  Configuration for tweening settings across all properties.

  | Option | Type | Default |
  | :--- | :--- | :--- |
  | `duration` | `TweenParamValue`{lang="ts-type"} | `1000` |
  | `ease` | `EasingParam`{lang="ts-type"} | `'out(2)'` |
  :::
::

## Returns

Returns a reactive proxy around the AnimeJS `AnimatableObject`{lang="ts-type"}
instance.

| Member | Type | Notes |
| :--- | :--- | :--- |
| `[property](value?)` | `(value?) => this`{lang="ts-type"} or the current value | Setter when called with a `number` or `number[]`, and returns `this`. Getter when called without arguments, and returns the current `number` or `number[]`. |
| `revert()` | `() => this`{lang="ts-type"} | Reverts targets to their pre-animation styles. Destructuring-unsafe: see the [destructuring caveat](#do-not-destructure-the-returned-instance). |

## Caveats

### Changing options alone does not rebuild the animatable

```ts
// wrong: changing durationRef does not alter the animatable instance
const durationRef = ref(300)
const anim = useAnimatable(target, () => ({ duration: durationRef.value }))

// right: supply explicit durations per setter or recreate when the target changes
anim.x(200, 500)
```

The underlying watcher bails out early when the normalized target element has
not changed. Mutating a ref passed inside `options` will not rebuild or update
the animatable controller. Pass override parameters directly to property setter
functions when dynamic durations or easings are needed.

### Do not destructure the returned instance

```ts
// wrong: copies methods once, losing the link on target change
const { revert } = useAnimatable(target, { duration: 300 })

// right: calls revert on the active proxy
const animator = useAnimatable(target, { duration: 300 })
animator.revert()
```

Destructuring properties or methods off the returned proxy binds them to the
initial instance. If the target element changes and rebuilds the controller,
destructured functions continue targeting the discarded instance. Retain the
proxy object and invoke methods directly on it.
