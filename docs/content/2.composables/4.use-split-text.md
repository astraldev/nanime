The `useSplitText` composable wraps the [splitText](https://animejs.com/documentation/text){target="_blank"} function from AnimeJS.

> A lightweight, responsive and accessible text utility function to split,
> clone and wrap lines, words and characters of an HTML Element.

## Arguments

::field-group
  :::field{required name="target" type="MaybeRef<SplitTextTargets>"}
  The element or selector containing the text to split.
  :::

  :::field{name="parameters" type="MaybeRefOrGetter<TextSplitterParams>"}
  See [AnimeJS Text documentation](https://animejs.com/documentation/text){target="_blank"} for split options like `lines`, `words`, `chars`.
  :::
::

## Return Value

Returns an object with reactive references to the split elements and computed accessors.

| Property     | Type                                                                            | Description                                                                             |
| :----------- | :------------------------------------------------------------------------------ | :-------------------------------------------------------------------------------------- |
| `lines`      | `Ref<HTMLElement[]>`{lang="ts-type"}                                            | Array containing line elements.                                                         |
| `words`      | `Ref<HTMLElement[]>`{lang="ts-type"}                                            | Array containing word elements.                                                         |
| `chars`      | `Ref<HTMLElement[]>`{lang="ts-type"}                                            | Array containing character elements.                                                    |
| `properties` | `ComputedRef<NonFunctionProperties<TextSplitter> | undefined>`{lang="ts-type"}  | Non-function properties of the underlying `TextSplitter` instance.                      |
| `methods`    | `ComputedRef<OnlyFunctionProperties<TextSplitter> | undefined>`{lang="ts-type"} | Methods (`revert`, `split`, `refresh`, etc.) of the underlying `TextSplitter` instance. |

## API

### Types

```ts
function useSplitText(
  target: MaybeRef<SplitTextTargets>,
  parameters?: MaybeRefOrGetter<TextSplitterParams>
): {
  lines: Ref<HTMLElement[]>,
  words: Ref<HTMLElement[]>,
  chars: Ref<HTMLElement[]>,
  properties: ComputedRef<NonFunctionProperties<TextSplitter> | undefined>,
  methods: ComputedRef<OnlyFunctionProperties<TextSplitter> | undefined>,
}
```

::collapsible{name="Type aliases"}
```ts
type SplitTargets = HTMLElement | string
type SplitTextTargets = SplitTargets | MaybeElementRef<HTMLElement> | null | undefined | MaybeElementRef<VueInstance>
```
::

See [AnimeJS Text documentation](https://animejs.com/documentation/text){target="_blank"} for more details.

## Caveats

- The arrays are empty until after mount. `splitText` needs the rendered text, so `lines`, `words` and `chars` start as `[]` and fill on the next tick. Pass the ref itself to an animation composable, or watch it, rather than reading `.value` synchronously.
- Destructuring is fine here. The composable returns refs rather than a `shallowReactive` instance, so `const { chars } = useSplitText(...)` keeps its reactivity.
- Every unit becomes an element. Splitting long copy into characters injects one span per character, which the browser then has to style and lay out. See [Performance](/getting-started/performance#keeping-split-text-short).

```ts
const heading = useTemplateRef('heading')
const { chars } = useSplitText(heading, { chars: true })

// chars is still [] here, and fills once the split runs
useAnimate(chars, { opacity: [0, 1], delay: stagger(40) })
```
