`useAnimate` wraps [`animate()`](https://animejs.com/documentation/animation){target="_blank"}
from AnimeJS. It rebuilds the animation when `target` or a parameter
changes, and reverts it when the component unmounts. A rebuild restarts the
animation unless `keepTime` is on.

## API

```ts
function useAnimate(
  target: AnimeTargets,
  parameters?: MaybeRefOrGetter<AnimationParams>,
  options?: NanimeInstanceOptions
): JSAnimation
```

::field-group
  :::field{required name="target" type="AnimeTargets"}
  Accepts everything AnimeJS accepts, plus template refs and component
  refs. A plain object [must be reactive](/composables/how-composables-run#plain-object-targets-must-be-reactive).
  :::

  :::field{name="parameters" type="MaybeRefOrGetter<AnimationParams>"}
  Accepts a plain object, a `ref`, a `reactive()` object or a getter. The
  animation rebuilds when it changes. Keys you pass override the
  [app-wide defaults](/guides/defaults#set-app-wide-defaults) by top-level
  key. Create `stagger()`
  [inside a getter](/composables/utilities#create-stagger-inside-a-getter-when-items-can-be-added)
  when items can be added.
  :::

  :::field{name="options" type="NanimeInstanceOptions"}
  Set `keepTime: true` so a rebuild continues from the current playhead.
  The default comes from [Configuration](/guides/configuration#set-module-options)
  and is `false` unless you set it.
  :::
::

Returns the AnimeJS `JSAnimation`{lang="ts-type"}. Call methods on the
returned object, as in `animation.play()`, because
[a destructured method throws](/composables/how-composables-run#do-not-destructure-the-returned-instance).
Properties such as `progress`
[do not update a template](/composables/how-composables-run#properties-do-not-update-templates).
