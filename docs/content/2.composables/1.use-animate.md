The `useAnimate` composable wraps the [animate](https://animejs.com/documentation/animation){target="_blank"} function from AnimeJS.

## Arguments

::field-group
  :::field{required name="target" type="AnimeTargets"}
  The value to animate. Can be a CSS selector, DOM element, Vue component, JS object, or an array of these.
  :::

  :::field{name="parameters" type="MaybeRefOrGetter<AnimationParams>"}
  See [AnimeJS Animatable Properties](https://animejs.com/documentation/animation/animatable-properties){target="_blank"}.
  :::
::

## Return Value

Returns a `shallowReactive` object wrapping the AnimeJS `JSAnimation` instance.

## API

### Types

```ts
function useAnimate(
  target: AnimeTargets,
  parameters?: MaybeRefOrGetter<AnimationParams>
): JSAnimation
```

::collapsible{name="Type aliases"}
```ts
type AnimeTargets = TargetsParam | MaybeElementRef | MaybeElementRef[]
```
::

See [AnimeJS Animation documentation](https://animejs.com/documentation/animation){target="_blank"} for more details.

## Caveats

- A target object created with `ref` will fail. Pass a `reactive` or `shallowReactive` object.
- Don't destructure the return value. The instance is wrapped in `shallowReactive`, and destructuring copies its values out once, disconnecting them from the instance.

```ts
// loses the connection to the instance
const { play } = useAnimate('.target', { ... })

// keeps it
const animation = useAnimate('.target', { ... })
animation.play()
```

::tip
Call `useAnimate` synchronously in `setup()` for it to react to `target` and `parameters`
changes. Called from `onMounted`, a watcher, or a handler, it runs in
[instant mode](/composables/introduction#instant-play): the animation is
created once and `parameters` are read only that first time.
::
