`useAnimate` wraps the [animate](https://animejs.com/documentation/animation){target="_blank"}
function from AnimeJS. It animates DOM elements, SVG nodes, and JavaScript
objects. When reactive parameters change, `nanime` rebuilds the animation
and [restarts it](/composables/introduction#when-does-an-animation-rebuild)
unless `keepTime: true` carries the playhead over.

## API

```ts
function useAnimate(
  target: AnimeTargets,
  parameters?: MaybeRefOrGetter<AnimationParams>,
  options?: NanimeInstanceOptions
): JSAnimation
```

::field-group
  :::field{required name="target" type="AnimeTargets"}
  Target element, SVG node, plain JavaScript object, or array of targets.
  Accepts CSS selectors, DOM elements, and component or template refs. A
  plain object [must be reactive](/composables/introduction#plain-object-targets-must-be-reactive).
  :::

  :::field{name="parameters" type="MaybeRefOrGetter<AnimationParams>"}
  Accepts a plain object, a `ref`, a `reactive()` object or a getter. The
  animation rebuilds when it changes. See the
  [AnimeJS animation documentation](https://animejs.com/documentation/animation){target="_blank"}
  for the options. Passed parameters are merged by top-level key over the
  [configured defaults](/guides/configuration#set-app-wide-defaults).
  :::

  :::field{name="options" type="NanimeInstanceOptions"}
  How the animation behaves when it rebuilds.

  | Option     | Type                      | Default |
  | :--------- | :------------------------ | :------ |
  | `keepTime` | `boolean`{lang="ts-type"} | `false` |
  :::
::

Returns a reactive proxy around the AnimeJS `JSAnimation`{lang="ts-type"}.
Its methods and properties are in the
[AnimeJS animation documentation](https://animejs.com/documentation/animation){target="_blank"}.
[Call methods on the returned object](/composables/introduction#do-not-destructure-the-returned-instance),
as in `animation.play()`. Properties like `progress`
[don't update a template](/composables/introduction#properties-do-not-update-templates).

::collapsible{name="Types"}
```ts
type AnimeTargets = TargetsParam | MaybeElementRef | MaybeElementRef[]

interface NanimeInstanceOptions {
  keepTime?: boolean
}
```
::

## Caveats

### Stagger a list that grows through a getter

```ts
// wrong: the stagger works out its steps for the first list only
useAnimate(items, { y: -16, delay: stagger(80), loop: true })

// right: a getter makes a new stagger for every rebuild
useAnimate(items, () => ({ y: -16, delay: stagger(80), loop: true }), { keepTime: true })
```

AnimeJS `stagger()` works out each item's step the first time it runs and
keeps them. Adding an item rebuilds the animation with the same parameters, so
the new item gets the first item's step. A getter creates a fresh stagger on
each rebuild, and `keepTime: true` keeps the others from restarting.
