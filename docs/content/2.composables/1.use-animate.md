`useAnimate` wraps [`animate()`](https://animejs.com/documentation/animation){target="_blank"}
from AnimeJS. It rebuilds the animation when `target` or a parameter
changes, and reverts it when the component unmounts. A rebuild restarts the
animation by default. The `rebuild` option can continue it from the
playhead or the current values instead.

## API

```ts
function useAnimate(
  target: AnimeTargets,
  parameters?: MaybeRefOrGetter<AnimationParams>,
  options?: NanimeAnimateOptions
): JSAnimation
```

::field-group
  :::field{name="target" type="AnimeTargets" required}
  Accepts everything AnimeJS accepts, plus template refs and component
  refs. A plain object [must be reactive](/composables/composable-lifecycle#plain-object-targets-must-be-reactive).
  :::

  :::field{name="parameters" type="MaybeRefOrGetter<AnimationParams>"}
  Accepts a plain object, a `ref`, a `reactive()` object or a getter. The
  animation rebuilds when it changes. Keys you pass override the
  [app-wide defaults](/guides/defaults#set-app-wide-defaults) by top-level
  key. Create `stagger()`
  [inside a getter](/composables/utilities#stagger-a-list-that-can-grow)
  when items can be added.
  :::

  :::field{name="options" type="NanimeAnimateOptions"}
  Set `rebuild` to choose what a rebuild does:

  - `'restart'` reverts the old animation and starts the new one from the
    original values.
  - `'keepTime'` reverts the old animation and starts the new one from the
    old animation's playhead.
  - `'keepValue'` cancels the old animation and starts the new one from the
    current values. The targets get their original values back when the
    component unmounts or `target` changes.

  Without a `rebuild` option, `useAnimate` uses the `rebuild` from
  `provideAnimeDefaults()`, then the one in `app.config.ts`, then the
  [module option](/guides/configuration#set-module-options), which is
  `'restart'` unless you change it.

  To keep the old animation running while the new one plays, set
  `composition: 'blend'` together with `'keepValue'`. With `'blend'` alone,
  the rebuild reverts the old animation, so AnimeJS has nothing to blend
  with. With both, `nanime` lets the old animation finish and starts the new
  one alongside it. `nanime` cancels a paused or infinitely looping old animation
  instead, as `'keepValue'` does on its own. Setting `composition: 'blend'` in the app-wide
  `animate` defaults has the same effect.

  ::::warning
  With `'blend'` and `'keepValue'`, each rebuild adds an animation that keeps
  running until it finishes (a finite `loop` runs until its last loop ends),
  and AnimeJS updates all of them on every frame.
  Frequent rebuilds with long durations leave many animations running at once
  and slow the page. Keep durations short or throttle what triggers the
  rebuild. See AnimeJS
  [composition](https://animejs.com/documentation/animation/animation-parameters/composition){target="_blank"}.
  ::::

  ::::note
  With `'keepValue'`, a looping animation whose property has no start value
  repeats from the value the property had at the rebuild. Write the start
  value, as in `x: [0, 200]`, to repeat between fixed values.
  ::::
  :::
::

Returns the AnimeJS `JSAnimation`{lang="ts-type"}. Call methods on the
returned object, as in `animation.play()`, because
[a destructured method throws](/composables/composable-lifecycle#do-not-destructure-the-returned-instance).
Properties such as `progress`
[do not update a template](/composables/composable-lifecycle#properties-do-not-update-templates).

## Keep the playhead when a parameter changes

:render-code-block-preview{src="examples/composables/AnimateKeepTimeDemo.vue"}

Click `Grow` while the boxes move. The `'restart'` box jumps back to the
left edge and starts the loop again. The `'keepTime'` box keeps its place
in the loop and takes the size the new loop has at that point.

## Blend a rebuild into the running animation

:render-code-block-preview{src="examples/composables/AnimateRebuildDemo.vue"}

Click `Spin` while the boxes slide. The `'keepValue'` box stops where it is
and spins, because the spin replaces its slide. The `'keepValue'` and
`'blend'` box spins while its slide keeps running at the same speed. Click
`Slide` to start over.
