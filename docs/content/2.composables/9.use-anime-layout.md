`useAnimeLayout` wraps [`createLayout()`](https://animejs.com/documentation/layout)
from AnimeJS. It creates the layout when the container mounts, rebuilds it
when `target` or a parameter value changes, and reverts it when the
component unmounts.

## API

```ts
function useAnimeLayout(
  target: MaybeRef<AnimeLayoutTargets>,
  parameters?: MaybeRefOrGetter<AnimeLayoutParams>
): BufferedProxyReturns<NanimeLayout>
```

::field-group
  :::field{name="target" type="MaybeRef<AnimeLayoutTargets>" required}
  The container whose children are animated. Accepts a CSS selector, a DOM
  element, a template ref or a component ref.
  :::

  :::field{name="parameters" type="MaybeRefOrGetter<AnimeLayoutParams>"}
  Accepts a plain object, a `ref` or a getter. The layout rebuilds when a
  value changes. See the
  [AnimeJS layout documentation](https://animejs.com/documentation/layout)
  for the options.
  :::
::

Returns a buffered proxy around the AnimeJS `AutoLayout`{lang="ts-type"}.
Its methods and properties are in the
[AnimeJS layout documentation](https://animejs.com/documentation/layout).
The members `nanime` adds or changes:

::field-group
  :::field{name="patch" type="(callback: () => unknown, params?: LayoutAnimationParams) => Promise<void>"}
  Added by `nanime`, and [the one to use for Vue state](#use-patch-not-update-for-vue-state).
  It records the layout, awaits `callback`, waits for Vue's `nextTick()`,
  then animates with `params`. The promise resolves when the animation
  finishes, or when a later `patch()` or `record()` interrupts it.
  :::

  :::field{name="record" type="() => this"}
  Records the current layout, and ends the wait of a pending `patch()`.
  Called from `setup()`, it runs once the layout is created.
  :::
::

`patch()` and other members return `undefined` until the container mounts,
so call `patch()` from an event handler or
[after mount](/composables/how-composables-run#read-properties-after-mount).

## Avoid common mistakes

### Use `patch()`, not `update()`, for Vue state

```ts
// wrong: animate() runs before Vue has patched the DOM
layout.update(() => items.value.reverse())

// right: patch() waits for nextTick() before animating
await layout.patch(() => items.value.reverse())
```

AnimeJS `update()` records, runs the callback and animates in one
synchronous call. Vue applies state changes to the DOM on the next tick, so
`animate()` compares the old DOM with itself and nothing moves. `update()`
still works for direct DOM changes, such as `appendChild`.
