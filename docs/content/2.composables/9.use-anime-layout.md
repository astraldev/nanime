`useAnimeLayout` wraps the [createLayout](https://animejs.com/documentation/layout){target="_blank"}
function from AnimeJS. It records the position and size of every element
inside a container. After a change, it animates each element from the
recorded state to the new one. `nanime` creates the layout once the
container mounts, reverts it on unmount, and rebuilds it only when the
container element changes or the parameters change in value. Callbacks such
as `onComplete` are left out of that comparison.

## API

```ts
function useAnimeLayout(
  target: MaybeRef<AnimeLayoutTargets>,
  parameters?: MaybeRefOrGetter<AnimeLayoutParams>
): BufferedProxyReturns<NanimeLayout>
```

::field-group
  :::field{required name="target" type="MaybeRef<AnimeLayoutTargets>"}
  The container whose children are animated. Accepts a CSS selector, a DOM
  element, a template ref or a component ref.
  :::

  :::field{name="parameters" type="MaybeRefOrGetter<AnimeLayoutParams>"}
  Accepts a plain object, a `ref` or a getter. The layout rebuilds when a
  value changes. See the
  [AnimeJS layout documentation](https://animejs.com/documentation/layout){target="_blank"}
  for the options.
  :::
::

Returns a buffered proxy around the AnimeJS `AutoLayout`{lang="ts-type"}.
Its methods and properties are in the
[AnimeJS layout documentation](https://animejs.com/documentation/layout){target="_blank"}.
The members `nanime` adds or changes:

| Member | Type | Notes |
| :--- | :--- | :--- |
| `patch(callback, params?)` | `(callback: () => unknown, params?: LayoutAnimationParams) => Promise<void>`{lang="ts-type"} | Added by `nanime`, and [the one to use for Vue state](#use-patch-not-update-for-vue-state). It calls `record()`, awaits `callback`, waits for Vue's `nextTick()`, then calls `animate(params)`. The promise resolves when the animation finishes, or when a later `patch()` or `record()` interrupts it. |
| `record()` | `() => this`{lang="ts-type"} | Can be called straight from `setup()`, and runs once the layout is created. |

`patch()` and other members return `undefined` until the container mounts,
so call `patch()` from an event handler or
[after mount](/composables/how-composables-run#read-properties-after-mount).

::collapsible{name="Types"}
```ts
type AnimeLayoutTargets = DOMTargetSelector | MaybeElementRef<HTMLElement | SVGElement | VueInstance | null> | null | undefined
type AnimeLayoutParams = AutoLayoutParams

type NanimeLayout = AutoLayout & {
  patch: (callback: () => unknown, params?: LayoutAnimationParams) => Promise<void>
}

type BufferedProxyReturns<T> = Exclude<UnwrapNestedRefs<T>, null | undefined>
```
::

## Caveats

### Use `patch()`, not `update()`, for Vue state

```ts
// wrong: animate() runs before Vue has patched the DOM
layout.update(() => items.value.reverse())

// right: patch() waits for nextTick() before animating
await layout.patch(() => items.value.reverse())
```

AnimeJS `update()` records, runs the callback and animates in one
synchronous call. Vue applies state changes to the DOM on the next tick, so
`animate()` compares the old DOM with itself and nothing moves. `patch()`
awaits `nextTick()` between the two steps. `update()` still works for
direct DOM changes, such as `appendChild`.
