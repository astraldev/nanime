`useWaapiAnimate` wraps [`waapi.animate()`](https://animejs.com/documentation/web-animation-api){target="_blank"}
from AnimeJS. It rebuilds the animation when `target` or a parameter
changes, and reverts it when the component unmounts.

## API

```ts
function useWaapiAnimate(
  target: WaapiTargets,
  parameters?: MaybeRefOrGetter<WAAPIAnimationParams>
): WAAPIAnimation
```

::field-group
  :::field{name="target" type="WaapiTargets" required}
  Accepts DOM elements, CSS selectors, template refs and component refs, or
  an array of them. WAAPI cannot animate plain objects, so use
  [`useAnimate`](/composables/use-animate) for those.
  :::

  :::field{name="parameters" type="MaybeRefOrGetter<WAAPIAnimationParams>"}
  Accepts a plain object, a `ref`, a `reactive()` object or a getter. The
  animation rebuilds when it changes. Create `stagger()`
  [inside a getter](/composables/utilities#stagger-a-list-that-can-grow)
  when items can be added.
  :::
::

Returns the AnimeJS `WAAPIAnimation`{lang="ts-type"}. Call methods on the
returned object, as in `animation.play()`, because
[a destructured method throws](/composables/composable-lifecycle#do-not-destructure-the-returned-instance).
Properties such as `progress`
[do not update a template](/composables/composable-lifecycle#properties-do-not-update-templates).
