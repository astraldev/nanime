`useWaapiAnimate` wraps the [waapi.animate](https://animejs.com/documentation/web-animation-api){target="_blank"}
function from AnimeJS. It animates DOM elements through the browser's Web
Animations API instead of a JavaScript loop.

When `target` or reactive parameters change, `nanime` rebuilds the animation.
It reverts when the component unmounts.

## Usage

:render-code-block-preview{src="examples/composables/WaapiAnimateDemo.vue"}

## Signature

```ts
function useWaapiAnimate(
  target: WaapiTargets,
  parameters?: MaybeRefOrGetter<WAAPIAnimationParams>
): WAAPIAnimation
```

## Parameters

::field-group
  :::field{name="target" type="WaapiTargets" required}
  The DOM element or elements to animate. Accepts CSS selectors, DOM elements,
  and component or template refs. WAAPI cannot animate plain objects, so use
  [`useAnimate`](/composables/use-animate) for those.
  :::

  :::field{name="parameters" type="MaybeRefOrGetter<WAAPIAnimationParams>"}
  Accepts a plain object, a `ref` or a getter. The animation rebuilds when
  it changes. See the
  [AnimeJS WAAPI documentation](https://animejs.com/documentation/web-animation-api){target="_blank"}
  for the options.
  :::
::

## Returns

Returns a reactive proxy around the AnimeJS `WAAPIAnimation`{lang="ts-type"}.
Its methods and properties are in the
[AnimeJS WAAPI documentation](https://animejs.com/documentation/web-animation-api){target="_blank"}.
Call methods on the returned object, as in `animation.play()`, because a
[destructured method throws](#do-not-destructure-the-returned-instance).
`progress` [doesn't update a template](#properties-do-not-update-templates)
either.

## Caveats

### Do not destructure the returned instance

```ts
// wrong: play() throws when called
const { play } = useWaapiAnimate('.target', parameters)

// right
const animation = useWaapiAnimate('.target', parameters)
animation.play()
```

The proxy hands back methods without their instance, so a destructured
`play()` runs with no `this` and throws. A destructured property such as
`progress` is a copy of the value at that moment. Keep the returned object
and call methods on it.

### Properties do not update templates

```ts
// wrong: progress never updates inside a template interpolation
// <p>{{ animation.progress }}</p>
```

Interpolating properties like `progress` in a template displays only their
initial value. `WAAPIAnimation`{lang="ts-type"} has no per-frame callback,
so nothing tells Vue when `progress` changes. [`useAnimate`](/composables/use-animate) runs its own render loop and
exposes an `onUpdate` callback instead, so reach for it when a template needs
to track progress live.
