`<AnimeTransition>` works like Vue's
[`<Transition>`](https://vuejs.org/guide/built-ins/transition.html), with
AnimeJS running the enter and leave animations instead of CSS classes. It
takes one child, toggled by `v-if`, `v-show` or a changed `key`.

## API

| Prop                  | Type                                                                                     | Default             | Description                                                                   |
| --------------------- | ---------------------------------------------------------------------------------------- | ------------------- | ----------------------------------------------------------------------------- |
| `animation`           | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimeTransitionAnimation`{lang="ts-type"} | `'fade'`            | Enter and leave together. A style name sets both, or pass `{ enter, leave }`. |
| `enterAnimation`      | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"}          | follows `animation` | Replaces the enter part of `animation`.                                       |
| `leaveAnimation`      | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"}          | follows `animation` | Replaces the leave part of `animation`.                                       |
| `mode`                | `'default'`, `'in-out'` or `'out-in'`                                                    | `'default'`         | Order when one element replaces another.                                      |
| `appear`              | `boolean`{lang="ts-type"}                                                                | `false`             | Run the enter animation on the first render too.                              |
| `completeOnTabHidden` | `boolean`{lang="ts-type"}                                                                | `false`             | Jump running animations to their end when the browser tab is hidden.          |

With no props, the element uses the `fade` style: 300ms in and 200ms out. A
default set in `app.config.ts` or with
[`provideAnimeDefaults()`](/guides/defaults#scope-defaults-to-part-of-the-app)
replaces it. With reduced motion on, the element jumps to its end state. See
[Accessibility](/guides/accessibility).

Vue's transition events pass through, and `nanime` calls the `done`
callback of `@enter` and `@leave` when the animation finishes.

### Set enter and leave with `animation`

`animation` takes a style name, which supplies that style's `enter` and
`leave`, or an object whose parts are each a style name or AnimeJS params.

```vue [App.vue]
<AnimeTransition animation="slide-up" />

<AnimeTransition :animation="{ enter: 'slide-up', leave: 'fade' }" />
```

`enterAnimation` and `leaveAnimation` win over `animation` for their part.
With `animation="fade"` and `enter-animation="scale"`, the element enters
with `scale` and leaves with `fade`.

`out-in` waits for the old element to finish leaving, `in-out` enters the

## Finish animations when the tab is hidden

AnimeJS pauses its animations while the browser tab is hidden, so a
leaving element stays half faded. Set `completeOnTabHidden` to jump the
component's running animations to their end instead.

To turn it on for every instance, set it in `nanime.components` in
`app.config.ts`:

```ts [app/app.config.ts]
export default defineAppConfig({
  nanime: {
    components: { transition: { completeOnTabHidden: true } },
  },
})
```

`transitionGroup` and `layoutGroup` take the same key.
