`<AnimeLayoutGroup>` wraps elements whose size or position changes, and
animates them to the new layout with AnimeJS
[layout](https://animejs.com/documentation/layout). It is the component
form of [`useAnimeLayout`](/composables/use-anime-layout).

## Usage

List the values that change the layout in `deps`. When one changes, the
children slide to their new places, and new ones fade in:

:render-code-block-preview{src="examples/components/LayoutGroupAccordionDemo.vue"}

| Prop            | Type                                  | Default                                             | Description                                                                                                                  |
| :-------------- | :------------------------------------ | :-------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------- |
| `deps`          | `unknown[]`{lang="ts-type"}           |                                                     | Values or getters that trigger a layout animation when they change, including nested changes.                                |
| `shallow`       | `boolean`{lang="ts-type"}             | `false`                                             | Animate only when an entry of `deps` is replaced, not when something nested inside it changes.                               |
| `elements`      | `AnimeLayoutElements`{lang="ts-type"} | every element inside                                | The elements that animate their own position and size: a selector, elements, components, or a list.                          |
| `layoutOptions` | `Omit<AutoLayoutParams, 'children'>`{lang="ts-type"} | `{ ease: spring({ bounce: 0.15, duration: 300 }) }` | AnimeJS `createLayout()` params, such as `duration` or `ease`. Setting either one replaces the default spring. Use `elements` for `children`. |
| `tag`           | `string`{lang="ts-type"}              | `'div'`                                             | Element rendered around the children.                                                                                        |
| `completeOnTabHidden` | `boolean`{lang="ts-type"} | `false` | Jump running animations to their end when the browser tab is hidden. See [finishing animations when the tab is hidden](/components/transitions#finish-animations-when-the-tab-is-hidden). |

Without `deps`, every re-render of the group measures every child and
animates, even when nothing moved, such as when a parent passes a new
object or array prop.

## Choose which elements animate

By default every element inside the group moves on its own, down to the
text inside a card. Pass `elements` to move only the cards:

```vue [components/CardGrid.vue]
<template>
  <AnimeLayoutGroup :deps="[view]" elements=".card">
    <div v-for="item in items" :key="item.id" class="card">
      <h3>{{ item.title }}</h3>
    </div>
  </AnimeLayoutGroup>
</template>
```

::warning
Anything inside a matched element jumps to its new spot halfway through
the move. Add it to `elements`, as in `".card, .card h3"`, to make it
slide. See the
[AnimeJS layout gotchas](https://animejs.com/documentation/layout/common-auto-layout-gotchas){target="_blank"}.
::

Instead of listing a selector for every element, give each element that
moves the same attribute, and pass that one attribute to `elements`. The
name is yours to pick:

```vue [components/TaggedCardGrid.vue]
<template>
  <AnimeLayoutGroup :deps="[view]" elements="[data-layout]">
    <div v-for="item in items" :key="item.id" class="card" data-layout>
      <h3 data-layout>{{ item.title }}</h3>
    </div>
  </AnimeLayoutGroup>
</template>
```

Three rules apply inside the group:

- An element removed with `v-if` vanishes at once, so use `v-show` to fade
  it out.
- A selector matches only inside its own group, and the group still
  measures everything inside it, so wrap only what moves.
- A `v-for` list that adds and removes items belongs in
  [`<AnimeTransitionGroup>`](/components/transitions#lists).

## Choosing between the two groups

`<AnimeLayoutGroup>` and
[`<AnimeTransitionGroup>`](/components/transitions#lists) both take
`deps` and `shallow`, but they animate different changes:

|                 | `<AnimeTransitionGroup>`                                          | `<AnimeLayoutGroup>`                                   |
| :-------------- | :---------------------------------------------------------------- | :----------------------------------------------------- |
| Built for       | `v-for` items that enter, leave and reorder                       | Mounted elements that change size or position          |
| Enter and leave | `enterAnimation` and `leaveAnimation` run on each item            | `v-show` fades an element, `v-if` removes it at once   |
| `deps`          | Adds triggers on top of list changes. `:deps="[]"` adds none      | The only trigger                                       |
| Timing          | `moveAnimation`: `duration`, `delay` and `ease`                   | `layoutOptions`: any AnimeJS `createLayout()` param    |
| What moves      | Every element inside the group                                    | Every element inside, or the ones `elements` picks     |
