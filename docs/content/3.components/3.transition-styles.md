A style is a named set of AnimeJS params for `enter`, `leave` and `move`.
`nanime` ships seven.

## Built-in styles

Pass a style name to
[`animation`](/components/transition#set-enter-and-leave-with-animation) to
use both its enter and its leave. To use it for only one of them, pass it to
`enterAnimation` or `leaveAnimation`.

```vue [App.vue]
<AnimeTransition animation="slide-up" />
<AnimeTransitionGroup animation="slide-up" :move-animation="{ duration: 500, ease: 'out(4)' }" />
```

| Style         | Enter                                                  | Leave                                           |
| :------------ | :----------------------------------------------------- | :---------------------------------------------- |
| `fade`        | opacity 0 to 1, 300ms, `out(3)`                        | opacity to 0, 200ms, `in(3)`                    |
| `slide-up`    | opacity 0 to 1, y 20 to 0, 350ms, `out(3)`             | opacity to 0, y to -20, 250ms, `in(3)`          |
| `slide-down`  | opacity 0 to 1, y -20 to 0, 350ms, `out(3)`            | opacity to 0, y to 20, 250ms, `in(3)`           |
| `slide-left`  | opacity 0 to 1, x 20 to 0, 350ms, `out(3)`             | opacity to 0, x to -20, 250ms, `in(3)`          |
| `slide-right` | opacity 0 to 1, x -20 to 0, 350ms, `out(3)`            | opacity to 0, x to 20, 250ms, `in(3)`           |
| `scale`       | opacity 0 to 1, scale 0.85 to 1, 300ms, `out(3)`       | opacity to 0, scale to 0.85, 200ms, `in(3)`     |
| `swap`        | opacity 0 to 1, y 10 to 0, scale 0.97 to 1, 260ms, `out(4)` | opacity to 0, y to -10, scale to 0.97, 160ms, `in(2)` |

None of the built-in styles set `move`, so a group's moves keep their own
timing unless you pass `moveAnimation`.
