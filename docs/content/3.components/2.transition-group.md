`<AnimeTransitionGroup>` works like Vue's
[`<TransitionGroup>`](https://vuejs.org/guide/built-ins/transition-group.html),
but always renders a wrapper element, a `div` by default. It animates
`v-for` items that enter and leave, and AnimeJS
[layout](https://animejs.com/documentation/layout) moves the rest: a move
is an item sliding to its new place after a sibling enters, leaves or
reorders.

## API

Every item needs a unique `:key`. With no props, items fade in over 250ms
and out over 150ms, and moves take 350ms with `out(3)`. This is the
group's own fallback, not the `fade` style, so `animation="fade"` gives
300ms in and 200ms out and leaves the move at 350ms. A default set in
`app.config.ts` or with
[`provideAnimeDefaults()`](/guides/defaults#scope-defaults-to-part-of-the-app)
replaces it.

| Prop                  | Type                                                                                                | Default                             | Description                                                                                                                   |
| :-------------------- | :-------------------------------------------------------------------------------------------------- | :---------------------------------- | :---------------------------------------------------------------------------------------------------------------------------- |
| `tag`                 | `string`{lang="ts-type"}                                                                            | `'div'`                             | Element rendered around the items. Unlike Vue's `<TransitionGroup>`, the group always renders a wrapper.                      |
| `animation`           | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimeTransitionGroupAnimation`{lang="ts-type"}       | the group fallback                  | Enter, leave and move together. A style name sets all three, or pass `{ enter, leave, move }`.                                |
| `enterAnimation`      | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"}                     | follows `animation`                 | Replaces the enter part.                                                                                                      |
| `leaveAnimation`      | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"}                     | follows `animation`                 | Replaces the leave part.                                                                                                      |
| `moveAnimation`       | `AnimeTransitionStyleName`{lang="ts-type"}, `AnimeMoveParams`{lang="ts-type"} or `false`            | `{ duration: 350, ease: 'out(3)' }` | How items move to a new position: a style name, `{ duration, delay, ease }`, or `false` to skip moves. Only those three settings apply. |
| `deps`                | `unknown[]`{lang="ts-type"}                                                                         |                                     | Values that trigger a move when they change, including nested changes. Adding, removing or reordering items always animates. A function entry is read as a getter. Without `deps`, every re-render measures all elements. |
| `shallow`             | `boolean`{lang="ts-type"}                                                                           | `false`                             | Animate only when an entry of `deps` is replaced, not when something nested inside it changes. Read once, when the group is created. |
| `appear`              | `boolean`{lang="ts-type"}                                                                           | `false`                             | Run the enter animation for the items present on the first render.                                                            |
| `absoluteLeave`       | `boolean`{lang="ts-type"}                                                                           | `true`                              | Take leaving items out of the flow as soon as they start leaving, so the rest close the gap while they animate out.            |
| `completeOnTabHidden` | `boolean`{lang="ts-type"}                                                                           | `false`                             | Jump running animations to their end when the browser tab is hidden.                                                         |

A style name in `animation` also supplies the style's `move` when it sets
one. None of the built-in styles set `move`, so the move stays
`{ duration: 350, ease: 'out(3)' }`. Custom and preset styles can set one.
`moveAnimation` wins over `animation` and over the style's `move`. Moves
are skipped when reduced motion is on.

::note
Give the group `position: relative` unless `absolute-leave` is `false`.
Leaving items switch to `position: absolute` and are placed against it.
::

Items that enter in the same update are counted together in DOM order, so
the first one starts first. The count restarts with each update, so one item
added later starts with no delay. Leaving items are counted the same way.

## Animate only when items move

Without `deps`, every re-render measures every element inside the group,
even when nothing moved. Pass `deps` to measure only when a value changes.

```vue [ItemList.vue]
<template>
  <AnimeTransitionGroup :deps="[view]">
    <div v-for="item in items" :key="item.id" />
  </AnimeTransitionGroup>
</template>
```

`:deps="[]"` keeps adding, removing and reordering as the only triggers.
A function entry is read as a getter, such as `() => state.view`, so the
group measures when the getter's result changes. Without `deps`, a parent
passing a new array prop is enough to measure.

Set `:move-animation="false"` when items only enter and leave. The group
then measures nothing. See
[Performance](/guides/performance#keep-group-items-small).
