`<AnimeTransitionGroup>` works like Vue's
[`<TransitionGroup>`](https://vuejs.org/guide/built-ins/transition-group.html).
It animates `v-for` items that enter and leave, and AnimeJS
[layout](https://animejs.com/documentation/layout) slides the other items
to their new positions.

## Usage

```vue [components/ItemList.vue]
<template>
  <AnimeTransitionGroup tag="ul" class="relative flex flex-wrap gap-2" :deps="[]">
    <li v-for="item in items" :key="item.id" />
  </AnimeTransitionGroup>
</template>
```

Items fade in over 250ms and out over 150ms. The group's own props are
below. `enterAnimation`, `leaveAnimation`, `appear` and
`completeOnTabHidden` take the same values as on
[`<AnimeTransition>`](/components/transitions).

| Prop            | Type                                                                                          | Default                             | Description                                                                                                         |
| :-------------- | :-------------------------------------------------------------------------------------------- | :---------------------------------- | :------------------------------------------------------------------------------------------------------------------ |
| `tag`           | `string`{lang="ts-type"}                                                                      | `'div'`                             | Element rendered around the items.                                                                                  |
| `animation`     | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimeTransitionGroupAnimation`{lang="ts-type"} |                                     | Enter, leave and move together. See [`animation`](/components/transitions#set-enter-and-leave-with-animation).      |
| `moveAnimation` | `AnimeTransitionStyleName`{lang="ts-type"}, `AnimeMoveParams`{lang="ts-type"} or `false`      | `{ duration: 350, ease: 'out(3)' }` | How items move to a new position: a style name, `{ duration, delay, ease }`, or `false` to skip moves.              |
| `absoluteLeave` | `boolean`{lang="ts-type"}                                                                     | `true`                              | Take leaving items out of the flow as soon as they start leaving, so the rest close the gap while they animate out. |
| `deps`          | `unknown[]`{lang="ts-type"}                                                                   |                                     | Values or getters that trigger a move animation when they change, including nested changes.                         |
| `shallow`       | `boolean`{lang="ts-type"}                                                                     | `false`                             | Animate only when an entry of `deps` is replaced, not when something nested inside it changes.                      |

A string `animation` also supplies the style's `move`. `moveAnimation`
wins over `animation` and over the style's `move`.

::note
Give the group `position: relative`. Leaving items switch to
`position: absolute` and are placed against it.
::

## Animate only when items move

Without `deps`, the group measures every element inside it on each
re-render, even when nothing moved. Pass `deps` to measure only when
something can move:

```vue [ItemList.vue]
<template>
  <!-- animates when items are added, removed or reordered -->
  <AnimeTransitionGroup :deps="[]">
    <div v-for="item in items" :key="item.id" />
  </AnimeTransitionGroup>

  <!-- also animates when view resizes the items -->
  <AnimeTransitionGroup :deps="[view]" :class="view">
    <div v-for="item in items" :key="item.id" />
  </AnimeTransitionGroup>
</template>
```

[Performance](/guides/performance#add-deps-to-groups)
covers what the measuring costs. The [Drive example](/examples/drive)
switches a group between three layouts while its items enter, leave and
expand.
