`<AnimeLayoutGroup>` wraps elements whose size or position changes, and
animates them to the new layout with AnimeJS
[layout](https://animejs.com/documentation/layout). It is the component
form of [`useAnimeLayout`](/composables/use-anime-layout).

## API

::field-group
  :::field{name="deps" type="unknown[]"}
  Values or getters that trigger a layout animation when they change,
  including nested changes. Without `deps`, every re-render measures every
  child and animates, even one caused by a parent passing a new object or
  array prop.
  :::

  :::field{name="shallow" type="boolean"}
  Animate only when an entry of `deps` is replaced, not when something nested
  inside it changes. Defaults to `false`.
  :::

  :::field{name="elements" type="AnimeLayoutElements"}
  The elements that animate their own position and size: a selector,
  elements, components, or a list. Defaults to every element inside the
  group.
  :::

  :::field{name="layoutOptions" type="Omit<AutoLayoutParams, 'children'>"}
  AnimeJS `createLayout()` params, such as `duration` or `ease`. Setting either
  one replaces the default spring. Use `elements` for `children`. Defaults to
  `{ ease: spring({ bounce: 0.15, duration: 300 }) }`.
  :::

  :::field{name="tag" type="string"}
  The element rendered around the children. Defaults to `'div'`.
  :::

  :::field{name="completeOnTabHidden" type="boolean"}
  Jump running animations to their end when the browser tab is hidden.
  Defaults to `false`.
  :::
::

## Choose which elements animate

By default every element inside the group moves on its own, down to the
text inside a card. Pass `elements` to move only the cards:

```vue [components/CardGrid.vue]
<template>
  <AnimeLayoutGroup :deps="[view]" elements=".card">
    <div v-for="item in items" :key="item.id" class="card">
      <h3>{{ item.title }}</h3>
    </div>
  </AnimeLayoutGroup>
</template>
```

::warning
Anything inside a matched element jumps to its new spot halfway through
the move. Add it to `elements`, as in `".card, .card h3"`, to make it
slide. See the
[AnimeJS layout gotchas](https://animejs.com/documentation/layout/common-auto-layout-gotchas).
::

::collapsible{name="Tag moving elements with one attribute"}
Give each element that moves the same attribute, and pass that one
attribute to `elements`. The name is yours to pick.

```vue [components/TaggedCardGrid.vue]
<template>
  <AnimeLayoutGroup :deps="[view]" elements="[data-layout]">
    <div v-for="item in items" :key="item.id" class="card" data-layout>
      <h3 data-layout>{{ item.title }}</h3>
    </div>
  </AnimeLayoutGroup>
</template>
```
::

A selector in `elements` matches only inside its own group.

## Choosing between the two groups

[`<AnimeTransitionGroup>`](/components/transition-group) and
`<AnimeLayoutGroup>` both take `deps` and `shallow`, but animate different
changes:

|                 | `<AnimeTransitionGroup>`                                     | `<AnimeLayoutGroup>`                                 |
| --------------- | ------------------------------------------------------------ | ---------------------------------------------------- |
| Built for       | `v-for` items that enter, leave and reorder                  | Mounted elements that change size or position        |
| Enter and leave | `enterAnimation` and `leaveAnimation` run on each item       | `v-show` fades an element, `v-if` removes it at once |
| `deps`          | Adds triggers on top of list changes. `:deps="[]"` adds none | The only trigger                                     |
| Timing          | `moveAnimation`: `duration`, `delay` and `ease`              | `layoutOptions`: any AnimeJS `createLayout()` param  |
| What moves      | Every element inside the group                               | Every element inside, or the ones `elements` picks   |
