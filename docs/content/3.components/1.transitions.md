`<AnimeTransition>` and `<AnimeTransitionGroup>` work like Vue's
[`<Transition>`](https://vuejs.org/guide/built-ins/transition.html) and
[`<TransitionGroup>`](https://vuejs.org/guide/built-ins/transition-group.html),
with AnimeJS running the animations instead of CSS classes. Vue's
transition events, such as `@after-enter`, and its modes pass through.

## Usage

`<AnimeTransition>` is a drop-in for Vue's
[`<Transition>`](https://vuejs.org/guide/built-ins/transition.html). It
takes one child, toggled by `v-if`, `v-show` or a changed `key`:

```vue
<template>
  <AnimeTransition>
    <div v-if="show" />
  </AnimeTransition>
</template>
```

With no props, the element fades in over 300ms and fades out over 200ms.

| Prop             | Type                                                                            | Default     | Description                                                                                                 |
| :--------------- | :------------------------------------------------------------------------------ | :---------- | :---------------------------------------------------------------------------------------------------------- |
| `enterAnimation` | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"} | `'fade'`    | How the element appears: a style name, or AnimeJS params.                                                   |
| `leaveAnimation` | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"} | `'fade'`    | How the element disappears: a style name, or AnimeJS params.                                                |
| `mode`           | `'default'`, `'in-out'` or `'out-in'`                                           | `'default'` | Order when one element replaces another. `out-in` waits for the old one to leave before the new one enters. |
| `appear`         | `boolean`{lang="ts-type"}                                                       | `false`     | Run the enter animation on the first render too.                                                            |

Style names come from the built-ins and from `app.config.ts`. See
[Transition styles](/components/transition-styles). To change a prop's
default across the app, see
[component defaults](/getting-started/configuration#set-component-defaults).

## Lists

AnimeJS [layout](https://animejs.com/documentation/layout) slides the other
items to their new positions.

`appear` works as on `<AnimeTransition>`. `enterAnimation` and
`leaveAnimation` take the same values, with a shorter default fade: 250ms
in and 150ms out. The group adds `tag`, `moveAnimation`, `absoluteLeave`,
`deps` and `shallow`:

| Prop             | Type                                                                                     | Default                             | Description                                                                                                         |
| :--------------- | :--------------------------------------------------------------------------------------- | :---------------------------------- | :------------------------------------------------------------------------------------------------------------------ |
| `enterAnimation` | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"}          | Fade in, 250ms `out(3)`             | How items appear: a style name, or AnimeJS params.                                                                  |
| `leaveAnimation` | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"}          | Fade out, 150ms `in(3)`             | How items disappear: a style name, or AnimeJS params.                                                               |
| `tag`            | `string`{lang="ts-type"}                                                                 | `'div'`                             | Element rendered around the items.                                                                                  |
| `moveAnimation`  | `AnimeTransitionStyleName`{lang="ts-type"}, `AnimeMoveParams`{lang="ts-type"} or `false` | `{ duration: 350, ease: 'out(3)' }` | How items move to a new position: a style name, `{ duration, delay, ease }`, or `false` to skip moves.              |
| `absoluteLeave`  | `boolean`{lang="ts-type"}                                                                | `true`                              | Take leaving items out of the flow as soon as they start leaving, so the rest close the gap while they animate out. |
| `deps`           | `unknown[]`{lang="ts-type"}                                                              |                                     | Values or getters that trigger a move animation when they change, including nested changes.                         |
| `shallow`        | `boolean`{lang="ts-type"}                                                                | `false`                             | Animate only when an entry of `deps` is replaced, not when something nested inside one changes.                     |

Without `deps`, the group measures every item on each re-render, even when
nothing moved. A parent that passes a new object or array prop on every
render triggers that measuring each time. With `deps`, the group measures
only when items are added, removed or reordered, or when a value in `deps`
changes. `:deps="[]"` animates list changes only. List the values that
resize items, such as a view toggle, so their moves still animate.

The [Drive example](/examples/drive) switches a group between three
layouts while its items enter, leave and expand.

For layout changes that are not list updates, use
[`<AnimeLayoutGroup>`](/components/layout-group) or
[`useAnimeLayout`](/composables/use-anime-layout).
