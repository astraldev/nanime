`<AnimeTransition>` and `<AnimeTransitionGroup>` work like Vue's
[`<Transition>`](https://vuejs.org/guide/built-ins/transition.html) and
[`<TransitionGroup>`](https://vuejs.org/guide/built-ins/transition-group.html),
with AnimeJS running the animations instead of CSS classes. Vue's
transition events, such as `@after-enter`, and its modes pass through.

## Usage

`<AnimeTransition>` is a drop-in for Vue's
[`<Transition>`](https://vuejs.org/guide/built-ins/transition.html). It
takes one child, toggled by `v-if`, `v-show` or a changed `key`:

```vue
<template>
  <AnimeTransition>
    <div v-if="show" />
  </AnimeTransition>
</template>
```

With no props, the element fades in over 300ms and fades out over 200ms.

| Prop             | Type                                                                            | Default     | Description                                                                                                 |
| :--------------- | :------------------------------------------------------------------------------ | :---------- | :---------------------------------------------------------------------------------------------------------- |
| `enterAnimation` | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"} | `'fade'`    | How the element appears: a style name, or AnimeJS params.                                                   |
| `leaveAnimation` | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"} | `'fade'`    | How the element disappears: a style name, or AnimeJS params.                                                |
| `mode`           | `'default'`, `'in-out'` or `'out-in'`                                           | `'default'` | Order when one element replaces another. `out-in` waits for the old one to leave before the new one enters. |
| `appear`         | `boolean`{lang="ts-type"}                                                       | `false`     | Run the enter animation on the first render too.                                                            |

Style names come from the built-ins and from `app.config.ts`. See
[Transition styles](/components/transition-styles).

## Lists

`<AnimeTransitionGroup>` animates `v-for` items that enter and leave.
AnimeJS [layout](https://animejs.com/documentation/layout) slides the other
items to their new positions.

::note
Give the group `position: relative`. Leaving items switch to
`position: absolute` and are placed against it.
::

`enterAnimation`, `leaveAnimation` and `appear` work as on
`<AnimeTransition>`. The group adds three props:

| Prop            | Type                                                                                     | Default                             | Description                                                                                                         |
| :-------------- | :--------------------------------------------------------------------------------------- | :---------------------------------- | :------------------------------------------------------------------------------------------------------------------ |
| `tag`           | `string`{lang="ts-type"}                                                                 | `'div'`                             | Element rendered around the items.                                                                                  |
| `moveAnimation` | `AnimeTransitionStyleName`{lang="ts-type"}, `AnimeMoveParams`{lang="ts-type"} or `false` | `{ duration: 400, ease: 'out(3)' }` | How items move to a new position: a style name, `{ duration, delay, ease }`, or `false` to skip moves.              |
| `absoluteLeave` | `boolean`{lang="ts-type"}                                                                | `true`                              | Take leaving items out of the flow as soon as they start leaving, so the rest close the gap while they animate out. |

The [media library example](/examples/media-library) switches a group
between four layouts while its items enter, leave and expand.

For layout changes that are not list updates, use
[`useAnimeLayout`](/composables/use-anime-layout).
