`<AnimeTransition>` works like Vue's
[`<Transition>`](https://vuejs.org/guide/built-ins/transition.html), with
AnimeJS running the animations instead of CSS classes. Vue's transition
events, such as `@after-enter`, pass through.

:render-code-block-preview{src="examples/components/TransitionAnimationPropDemo.vue"}

## Usage

It takes one child, toggled by `v-if`, `v-show` or a changed `key`. With
no props, the element fades in over 300ms and fades out over 200ms.

```vue
<template>
  <AnimeTransition>
    <div v-if="show" />
  </AnimeTransition>
</template>
```

| Prop                  | Type                                                                                      | Default     | Description                                                                                                 |
| :-------------------- | :---------------------------------------------------------------------------------------- | :---------- | :---------------------------------------------------------------------------------------------------------- |
| `animation`           | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimeTransitionAnimation`{lang="ts-type"} |             | Enter and leave together. See [Set enter and leave with `animation`](#set-enter-and-leave-with-animation).  |
| `enterAnimation`      | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"}           | `'fade'`    | How the element appears: a style name, or AnimeJS params.                                                   |
| `leaveAnimation`      | `AnimeTransitionStyleName`{lang="ts-type"} or `AnimationParams`{lang="ts-type"}           | `'fade'`    | How the element disappears: a style name, or AnimeJS params.                                                |
| `mode`                | `'default'`, `'in-out'` or `'out-in'`                                                     | `'default'` | Order when one element replaces another. `out-in` waits for the old one to leave before the new one enters. |
| `appear`              | `boolean`{lang="ts-type"}                                                                 | `false`     | Run the enter animation on the first render too.                                                            |
| `completeOnTabHidden` | `boolean`{lang="ts-type"}                                                                 | `false`     | Jump running animations to their end when the browser tab is hidden.                                        |

Style names come from the built-ins, `app.config.ts` and the active
[preset](/guides/presets). See
[Transition styles](/components/transition-styles). To change a prop's
default across the app, see
[component defaults](/guides/configuration#set-app-wide-defaults).

## Set enter and leave with `animation`

A string is a transition style name and supplies the style's `enter` and
`leave`. An object sets each part on its own:

```vue [App.vue]
<AnimeTransition animation="fade" />

<AnimeTransition :animation="{ enter: 'slide-up', leave: 'fade' }" />
```

An individual prop wins over `animation` for its part. With
`animation="fade"` and `enter-animation="scale"`, the element enters with
`scale` and leaves with `fade`.

`animation` works as a default too, under `nanime.components` in
`app.config.ts`, in
[`provideAnimeDefaults()`](/guides/configuration#scope-defaults-to-part-of-the-app)
and in a preset. See [defaults](/guides/configuration#set-app-wide-defaults)
and [presets](/guides/presets).
[`<AnimeTransitionGroup>`](/components/transition-group) takes the same
prop and adds `move`.

## Finish animations when the tab is hidden

AnimeJS pauses its animations while the browser tab is hidden. Until the
tab is visible again, a leaving element stays half faded.

Set `completeOnTabHidden` to jump the component's running animations to
their end as soon as the tab is hidden. Other animations on the page still
pause. `<AnimeTransitionGroup>` and
[`<AnimeLayoutGroup>`](/components/layout-group) take it too.

```vue [components/ToastHost.vue]
<AnimeTransition complete-on-tab-hidden>
  <Toast v-if="open" />
</AnimeTransition>
```

To turn it on for every instance of a component, set it in
[component defaults](/guides/configuration#set-app-wide-defaults):

```ts [app/app.config.ts]
export default defineAppConfig({
  nanime: {
    components: { transitionGroup: { completeOnTabHidden: true } },
  },
})
```
