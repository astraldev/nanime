`<ATransitionSlide>` wraps Vue's `<Transition>` (or `<TransitionGroup>`) and drives
the enter and leave animations with AnimeJS. The component name carries your
configured [prefix](/getting-started/configuration), `A` by default.

## Props

| Prop | Type | Default | Notes |
|---|---|---|---|
| `axis` | `'x' \| 'y'` or a per-phase pair | `'y'` | Direction of travel |
| `offset` | number, `'<n>px'`, `'<n>%'`, or a per-phase pair | `'-20%'` | How far the element travels |
| `duration` | number, `[enter, leave]`, or `{ enter, leave }` | `{ enter: 300, leave: 300 }` | |
| `delay` | same shape as `duration` | — | |
| `ease` | easing | `'out'` | |
| `noOpacity` | boolean | `false` | Skip the opacity fade, move only |
| `tag` | element tag | `'div'` | Group mode only |
| `mode` | `'out-in' \| 'in-out'` | `'out-in'` | Single mode only |
| `useWaapi` | boolean | `true` | Single mode only |
| `group` | boolean | `false` | Switch to `<TransitionGroup>` |

Every per-phase prop takes one value for both phases, a `[enter, leave]` tuple, or
an `{ enter, leave }` object.

```vue
<ATransitionSlide axis="x" :duration="[300, 200]" :offset="{ enter: '-20%', leave: '20%' }">
  <div :key="panel">Panel {{ panel }}</div>
</ATransitionSlide>
```

## Groups

Set `group` to animate a list. The component switches to `<TransitionGroup>` and
records positions before each change, so items that merely move animate to their
new position rather than jumping.

Group mode changes which props apply:

- `useWaapi` is unavailable — group transitions always use the standard engine.
- `layoutOptions` and `animateOptions` become available, and are passed to
  [`useAnimeLayout`](/composables/use-anime-layout) underneath.
- `mode` does not apply.

The type definition enforces this, so an invalid combination fails to compile.
