Proxies are not called on their own. Each returns a value that goes inside
animation parameters, and the animation applies it.

## Text

From `#nanime/proxies/text`.

| Export         | Description                                                           |
| -------------- | ---------------------------------------------------------------------- |
| `scrambleText` | A scramble and reveal effect, used as an `innerHTML` animation value  |

```ts
import { scrambleText } from '#nanime/proxies/text'

const tl = useAnimeTimeline({ loop: true })

tl.add(target, {
  innerHTML: scrambleText({
    text: 'hello world',
    chars: 'symbols',
  }),
})
```

For scrambling an element's text on its own, use
[`useScrambleText`](/composables/use-scramble-text). This proxy is for
placing a scramble inside a timeline or another animation. The
[AnimeJS documentation](https://animejs.com/documentation/text/scrambletext){target="_blank"} lists every option.

## SVG

From `#nanime/proxies/svg`.

| Export             | Description                                              |
| ------------------ | --------------------------------------------------------- |
| `morphTo`          | Morphs one path into another, as a `d` animation value   |
| `createMotionPath` | Returns `x`, `y` and `rotate` values that follow a path  |
| `createDrawable`   | Wraps a path so its stroke can be drawn in and out       |

```ts
import { morphTo } from '#nanime/proxies/svg'

const path = useTemplateRef('path')

useAnimate(path, {
  d: morphTo('#target-path'),
  duration: 800,
  ease: 'inOutQuad',
})
```

`createMotionPath` returns three values at once, so spread it into the
parameters. The element follows the path and turns to face along it:

```ts
import { createMotionPath } from '#nanime/proxies/svg'

const car = useTemplateRef('car')
const road = useTemplateRef('road')

useAnimate(car, {
  ...createMotionPath(road.value),
  ease: 'linear',
  duration: 4000,
})
```

A motion path displaces an element rather than placing its box. Author the
shape with the point you want on the line sitting at the origin.

Both groups are also re-exported together from `#nanime/proxies`.
