`#nanime/easings` re-exports every easing function from
[AnimeJS](https://animejs.com){target="_blank"}. Use them when you need a curve
instead of an easing name.

```ts
import { eases, cubicBezier } from '#nanime/easings'

eases.outBack(3)
cubicBezier(.7, .1, .5, .9)
```

The [AnimeJS easings documentation](https://animejs.com/documentation/easings){target="_blank"} has the full list.

AnimeJS names its easings `outQuad` and `inOutSine`, not `easeOutQuad`. An
unrecognised name fails silently and falls back to linear.
