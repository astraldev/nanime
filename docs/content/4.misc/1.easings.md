You can access all easings provided by [AnimeJS](https://animejs.com){target="_blank"} via `#nanime/easings`.

```ts
import { eases, cubicBezier } from '#nanime/easings'

eases.outBack(3)
cubicBezier(.7, .1, .5, .9)
```
