`#nanime/utils` re-exports the AnimeJS
[utilities](https://animejs.com/documentation/utilities){target="_blank"},
along with `animate` and `createTimer` for imperative work outside a
composable.

```ts
import { snap, lerp, mapRange } from '#nanime/utils'

snap(30)
lerp(0, 100)
mapRange(0, 100, 0, 200)
```

## Stagger

[stagger()](https://animejs.com/documentation/utilities/stagger){target="_blank"}
gives each target a slightly different delay or value. A group then animates
one after another instead of all at once.

## Snap

[snap()](https://animejs.com/documentation/utilities/snap){target="_blank"}
rounds a number to the nearest increment. Called with only the increment, it
returns a snapping function, which is what a draggable's `snap` option takes.
