Everything on this page is optional. Module options go in `nuxt.config.ts`.
App-wide settings go under the `nanime` key in `app.config.ts`.
[Defaults](/guides/defaults) covers default props and parameters.

## Set module options

| Option | Type | Default | What it does |
| :--- | :--- | :--- | :--- |
| `composables` | `boolean` | `true` | Auto-imports the composables and `provideAnimeDefaults()`. With `false`, import them from `#nanime/composables`. |
| `components` | `boolean` | `true` | Registers `<AnimeTransition>`, `<AnimeTransitionGroup>` and `<AnimeLayoutGroup>`. |
| `rebuild` | `'restart'`, `'keepTime'` or `'keepValue'` | `'restart'` | How `useAnimate`, `useAnimeTimeline` and `useScrambleText` rebuild. `'keepTime'` continues from the playhead. `'keepValue'` starts from the current values and applies to `useAnimate` only. |
| `reducedMotion` | `'never'`, `'system'` or `'always'` | `'never'` | When `nanime` animations jump to their end state. `'system'` follows the visitor's `prefers-reduced-motion` setting. See [Accessibility](/guides/accessibility). |
| `vueuseAliases` | `boolean` or `{ useAnimate?, useDraggable? }`{lang="ts-type"} | `false` | Auto-import names for the `nanime` composables that VueUse also auto-imports. See [Use with VueUse](#use-with-vueuse). |

`rebuild` replaces the 0.3 `keepTime` option. The
[changelog](/changes/changelog) has the replacement for each use.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nanime'],
  nanime: {
    rebuild: 'keepTime',
    reducedMotion: 'system',
  },
})
```

The `rebuild` and `reducedMotion` options are also copied to
`runtimeConfig.public.nanime`. That lets an environment variable such as
`NUXT_PUBLIC_NANIME_REDUCED_MOTION=always` override them at deploy time.

## Use with VueUse

`@vueuse/nuxt` also auto-imports a `useAnimate` and a `useDraggable`. By
default the app gets the `nanime` versions, and the build logs a warning
that names both. Set `vueuseAliases: true` to auto-import the `nanime`
versions as `useAnimeAnimate` and `useAnimeDraggable`. VueUse then keeps
the plain names.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@vueuse/nuxt', 'nanime'],
  nanime: {
    // or true for useAnimeAnimate and useAnimeDraggable
    vueuseAliases: { useDraggable: 'useAnimeDrag' },
  },
})
```

A composable left out of the map keeps its plain name, and the warning
lists it. Without VueUse, `vueuseAliases` changes nothing.

## Set app-wide options

The `nanime` key in `app.config.ts` is typed `NanimeConfig`. On Nuxt 3 the
file is in the project root. On Nuxt 4 it sits in `app/`.

| Key | Type | Default | What it sets |
| :--- | :--- | :--- | :--- |
| `rebuild` | `'restart'`, `'keepTime'` or `'keepValue'` | unset (falls back to the module option, then `'restart'`) | Default `rebuild` mode for the app. |
| `reducedMotion` | `'never'`, `'system'` or `'always'` | unset (falls back to the module option, then `'never'`) | Reduced motion for the app. Can change at runtime. |
| `preset` | `AnimationPreset` | none | The motion preset. See [Presets](/guides/presets). |
| `transitions` | `Record<string, AnimeTransitionStyle>` | `{}` | Named transition styles on top of the built-ins. See [Add your own transition styles](#add-your-own-transition-styles). |
| `components` | `NanimeComponentDefaults` | `{}` | Default props for the three components. See [Defaults](/guides/defaults). |
| `composables` | `NanimeComposableDefaults` | `{}` | Default parameters for `useAnimate` and `useDraggable`. See [Defaults](/guides/defaults). |

`updateAppConfig()` changes these values at runtime. Components use the
new values on their next render or run. A composable reads `rebuild`
once, when you call it, and its other defaults each time it builds or
rebuilds an animation.

## Add your own transition styles

Define a style under `nanime.transitions` in `app.config.ts`, then pass its
name to `animation`, `enterAnimation`, `leaveAnimation` or `moveAnimation`.
A style is an object with up to three parts:

| Part | Type | Used by |
| :--- | :--- | :--- |
| `enter` | `AnimationParams`{lang="ts-type"} | `<AnimeTransition>` and `<AnimeTransitionGroup>`, for an element that appears. |
| `leave` | `AnimationParams`{lang="ts-type"} | `<AnimeTransition>` and `<AnimeTransitionGroup>`, for an element that disappears. |
| `move` | `{ duration?, delay?, ease? }`{lang="ts-type"} | `<AnimeTransitionGroup>`, for an item that slides to a new position. |

A part you leave out uses the component's default. The demo plays six styles
from this site's `app.config.ts`. The code shows three of them.

```ts [app/app.config.ts]
export default defineAppConfig({
  nanime: {
    transitions: {
      shake: {
        enter: { opacity: [0, 1], x: [0, -10, 10, -6, 6, 0], duration: 500, ease: 'inOut(2)' },
        leave: { opacity: 0, x: [0, 8, -8, 0], duration: 300, ease: 'in(2)' },
      },
      explode: {
        enter: { opacity: [0, 1], scale: [0.5, 1], duration: 350, ease: 'outBack(3)' },
        leave: { opacity: 0, scale: 2, filter: ['blur(0px)', 'blur(10px)'], duration: 400, ease: 'out(3)' },
      },
      skew: {
        enter: { opacity: [0, 1], x: [-24, 0], skewX: [20, 0], duration: 450, ease: 'out(4)' },
        leave: { opacity: 0, x: 24, skewX: -20, duration: 250, ease: 'in(3)' },
      },
    },
  },
})
```

A function value receives the element, its index and the elements that
enter or leave together. `delay: (el, index) => index * 40` staggers them.
`ease`, `keyframes`, `modifier` and the callbacks are not called this way.
[Chain steps with keyframes](/components/transition#chain-steps-with-keyframes)
shows a style whose properties step through several values.
