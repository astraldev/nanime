Everything on this page is optional. Module options go in `nuxt.config.ts`.
App-wide defaults go under the `nanime` key in `app.config.ts`.
`provideAnimeDefaults()` overrides most of them for part of the app.

A setting can live in more than one place. Where two places set the same
setting, the narrower scope wins.

| Setting | `nuxt.config.ts` | `app.config.ts` (`nanime`) | `provideAnimeDefaults()` | Props or call options |
| :--- | :--- | :--- | :--- | :--- |
| `composables` (auto-import) | yes | no | no | no |
| `components` (register) | yes | no | no | no |
| `keepTime` | yes | yes | yes | yes, `options.keepTime` |
| `reducedMotion` | yes | yes | no | no |
| `preset` | no | yes | yes | no |
| `transitions` (named styles) | no | yes | no | no |
| Component defaults | no | `components` | `transition`, `transitionGroup`, `layoutGroup` | yes, props |
| Composable defaults | no | `composables` | `composables` | yes, parameters |

## Set module options

| Option | Type | Default | What it does |
| :--- | :--- | :--- | :--- |
| `composables` | `boolean` | `true` | Auto-imports the composables and `provideAnimeDefaults()`. With `false`, import them from `#nanime/composables`. |
| `components` | `boolean` | `true` | Registers `<AnimeTransition>`, `<AnimeTransitionGroup>` and `<AnimeLayoutGroup>`. |
| `keepTime` | `boolean` | `false` | Default `keepTime` for `useAnimate`, `useAnimeTimeline` and `useScrambleText`. |
| `reducedMotion` | `'never'`, `'system'` or `'always'` | `'never'` | When `nanime` animations jump to their end state. |

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nanime'],
  nanime: {
    keepTime: true,
    reducedMotion: 'system',
  },
})
```

With `composables: false`, import each composable from
`#nanime/composables`. With `components: false`, nothing is registered. The
component code and its styles are bundled only if you import a component,
for example from `nanime/vue`.

Both `keepTime` and `reducedMotion` are copied into public runtime config
as `runtimeConfig.public.nanime`. A value already set there wins over the
module option, so `NUXT_PUBLIC_NANIME_REDUCED_MOTION=always` overrides
`nuxt.config.ts` at deploy time.

A `keepTime` passed to one composable call wins over the module option:

```ts
useAnimate(target, { x: 100 }, { keepTime: false })
```

`reducedMotion: 'system'` follows `prefers-reduced-motion`.
[Accessibility](/guides/accessibility) covers the values and shows a
runtime toggle.

## Set app-wide defaults

The `nanime` key in `app.config.ts` is typed `NanimeConfig`. The file is
bundled into the client, so it can hold functions, such as a transition
style's `delay` or an easing.

On Nuxt 3 the file is `app.config.ts` in the project root. On Nuxt 4 it
sits in `app/`.

In a plain Vue app, `configureNanime()` takes the place of `app.config.ts`.
See [Vue without Nuxt](/guides/vue).

| Key | Type | Default | What it sets |
| :--- | :--- | :--- | :--- |
| `keepTime` | `boolean` | unset, so the module option, then `false` | `keepTime` for the app. |
| `reducedMotion` | `'never'`, `'system'` or `'always'` | unset, so the module option, then `'never'` | Reduced motion for the app. Can change at runtime. |
| `preset` | `AnimationPreset` | none | The motion preset. See [Presets](/guides/presets). |
| `transitions` | `Record<string, AnimeTransitionStyle>` | `{}` | Named transition styles on top of the built-ins. See [Transition styles](/components/transition-styles). |
| `components` | `NanimeComponentDefaults` | `{}` | Default props for the three components. |
| `composables` | `NanimeComposableDefaults` | `{}` | Default parameters for `useAnimate` and `useDraggable`. |

```ts [app/app.config.ts]
export default defineAppConfig({
  nanime: {
    components: {
      transition: { animation: 'slide-up', mode: 'out-in' },
      transitionGroup: { animation: 'swap', moveAnimation: { duration: 600, ease: 'out(4)' } },
      layoutGroup: { layoutOptions: { duration: 500 } },
    },
    composables: {
      animate: { duration: 500, ease: 'out(3)' },
      draggable: { releaseEase: 'out(3)', dragSpeed: 2 },
    },
  },
})
```

A prop passed to a component wins over its default. A composable call
merges its parameters over the defaults by top-level key, so a passed key
wins where both set it.

`updateAppConfig()` changes these values at runtime. The next render or
animation run picks up `reducedMotion`, `transitions`, `preset` and
component defaults. `nanime.composables.animate` is read when an animation
rebuilds. `keepTime` and `nanime.composables.draggable` are read when a
composable is created.

### What can be a default

| Entry | Props that can be defaults | Built-in value when unset |
| :--- | :--- | :--- |
| `components.transition` | `animation`, `enterAnimation`, `leaveAnimation`, `mode`, `appear`, `completeOnTabHidden` | `fade` in 300ms, out 200ms, `mode: 'default'`, `appear: false` |
| `components.transitionGroup` | `tag`, `animation`, `enterAnimation`, `leaveAnimation`, `moveAnimation`, `appear`, `absoluteLeave`, `shallow`, `completeOnTabHidden` | in 250ms `out(3)`, out 150ms `in(3)`, move 350ms `out(3)`, `tag: 'div'`, `absoluteLeave: true` |
| `components.layoutGroup` | `tag`, `shallow`, `layoutOptions`, `elements` (selector string or list of strings), `completeOnTabHidden` | `spring({ bounce: 0.15, duration: 300 })`, `tag: 'div'` |
| `composables.animate` | any `AnimationParams` | none |
| `composables.draggable` | any `DraggableParams` except `trigger` and `container` | none |

`deps` is never a default, because each component passes values for its
own list instance. Element refs and component instances exist only inside
a component, so they cannot be defaults either.

In `nanime.composables`, `animate` is typed `AnimationParams`, and
`draggable` is typed `DraggableParams` without `trigger` and `container`,
which belong to one element.

### Set enter, leave and move with `animation`

`animation` sets enter and leave from one prop:

- A style name supplies the style's `enter` and `leave`, and on the group
  its `move`.
- An object sets each part: `{ enter, leave }`, and on the group
  `{ enter, leave, move }`. `move` also takes `false`.
- `enterAnimation`, `leaveAnimation` and `moveAnimation` win over
  `animation` for their part.

[Transitions](/components/transitions#set-enter-and-leave-with-animation)
covers the prop in full.

## Scope defaults to part of the app

`provideAnimeDefaults()` sets defaults for everything rendered below the
component that calls it. Call it in `<script setup>` of the parent.
Siblings and ancestors are not affected.

The argument is typed `NanimeDefaults`:

| Key | Type | Notes |
| :--- | :--- | :--- |
| `transition`, `transitionGroup`, `layoutGroup` | same as the `components` entries | Replaces the same entry from an outer call whole. |
| `composables` | `{ animate?, draggable? }` | Each replaces the outer one whole. |
| `preset` | `AnimationPreset` | Replaces the app-wide preset for everything below. |
| `keepTime` | `boolean` | Default `keepTime` for the composables inside. |

It can be an object, a ref or a getter. An entry set to `undefined` keeps
the outer one. `transitions` and `reducedMotion` are not accepted, because
they stay app-wide.

```vue [components/SettingsPanel.vue]
<script setup lang="ts">
provideAnimeDefaults({
  transition: { animation: 'scale' },
  composables: { animate: { duration: 300 } },
  keepTime: true,
})
</script>
```

A getter returns the defaults object, so the defaults can follow reactive
state:

```vue [components/ThemeScope.vue]
<script setup lang="ts">
const compact = ref(false)

provideAnimeDefaults(() => ({
  transition: { mode: compact.value ? 'out-in' : 'default' },
}))
</script>
```

## How a default is picked

Each default comes from the first source that sets it:

1. The prop on the component, or the parameters passed to the composable
   call.
2. The nearest `provideAnimeDefaults()` that sets that entry.
3. `nanime.components` or `nanime.composables` in `app.config.ts`.
4. The active [preset](/guides/presets).
5. The component's or composable's built-in default.

`keepTime` has its own chain: the composable's own option, the nearest
`provideAnimeDefaults()` that sets it, `nanime.keepTime` in
`app.config.ts`, the `keepTime` module option, then `false`.

Example: `app.config.ts` sets `components.transition.animation` to
`'slide-up'`, and a `provideAnimeDefaults({ transition: { mode: 'out-in' } })`
wraps a panel. Inside the panel, `<AnimeTransition>` uses `mode: 'out-in'`
from the provider and `slide-up` from `app.config.ts`, because the
provider entry sets no `animation`. A bare
`<AnimeTransition animation="scale">` in the panel wins over both.

### Component props resolve per prop

- A prop set to `undefined` falls through to the next source. The
  components declare boolean props with `default: undefined`, so passing
  `false` differs from leaving the prop out.
- A provider entry replaces the matching entry from an outer
  `provideAnimeDefaults()` call whole, and keeps the other components'
  entries.
- Within an entry, each prop sits over the `app.config.ts` value for that
  prop.
- `animation`, `enterAnimation`, `leaveAnimation` and `moveAnimation`
  resolve per part (enter, leave, move). Each part comes from the highest
  layer that sets it. Params inside one part, such as `layoutOptions` or an
  animation object, replace the lower value whole.

### Composable entries are chosen whole

The first layer that sets a composable's entry is used whole, so a key left
`undefined` inside it falls to the built-in default, not to a lower layer.
A composable call then merges its parameters over the chosen entry by
top-level key.
