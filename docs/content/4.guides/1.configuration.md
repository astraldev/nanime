Everything on this page is optional. Module options go in `nuxt.config.ts`.
Defaults for the whole app go under the `nanime` key in `app.config.ts`.
`provideAnimeDefaults()` overrides most of them for part of the app.

## Set app-wide defaults

`app.config.ts` is bundled into the client, so it can hold functions, such
as a transition style's `delay` or an easing. The `nanime` key is typed
`NanimeConfig`:

| Key | What it sets |
| :--- | :--- |
| `keepTime` | `keepTime` for the app, over the module option. |
| `reducedMotion` | The reduced motion setting for the app, over the module option. |
| `preset` | The motion preset for the app. [Presets](/guides/presets) covers it. |
| `transitions` | Named transition styles, on top of the built-ins. See [Transition styles](/components/transition-styles). |
| `components` | Default props for `<AnimeTransition>`, `<AnimeTransitionGroup>` and `<AnimeLayoutGroup>`. |
| `composables` | Default parameters for `useAnimate` and default options for `useDraggable`. |

```ts [app/app.config.ts]
export default defineAppConfig({
  nanime: {
    components: {
      transition: { animation: 'slide-up', mode: 'out-in' },
      transitionGroup: { animation: 'swap', moveAnimation: { duration: 600, ease: 'out(4)' } },
      layoutGroup: { layoutOptions: { duration: 500 } },
    },
    composables: {
      animate: { duration: 500, ease: 'out(3)' },
      draggable: { releaseEase: 'out(3)', dragSpeed: 2 },
    },
  },
})
```

A prop passed to a component wins over its default. A composable call
merges its parameters over the defaults by top-level key, so a passed key
wins where both set it.

`updateAppConfig()` changes these values at runtime. The next render or
animation run picks up `reducedMotion`, `transitions`, `preset` and
component defaults. `nanime.composables.animate` is read when an animation
rebuilds. `keepTime` and `nanime.composables.draggable` are read when a
composable is created.

::collapsible{name="Component and composable default details"}
The keys under `nanime.components` are `transition`, `transitionGroup` and
`layoutGroup`.

`animation` sets enter and leave from one prop:

- A style name supplies the style's `enter` and `leave`, and on the group
  its `move`.
- An object sets each part: `{ enter, leave }`, and on the group
  `{ enter, leave, move }`. `move` also takes `false`.
- `enterAnimation`, `leaveAnimation` and `moveAnimation` win over
  `animation` for their part.

Defaults cannot set `deps`, because each component passes values for its
own list instance. `elements` takes a selector string or a list of selector
strings. Element refs and component instances exist only inside a
component, so they cannot be defaults.

In `nanime.composables`, `animate` is typed `AnimationParams`, and
`draggable` is typed `DraggableParams` without `trigger` and `container`,
which belong to one element.
::

## Set module options

| Option | Type | Default | What it does |
| :--- | :--- | :--- | :--- |
| `composables` | `boolean` | `true` | Auto-imports the composables and `provideAnimeDefaults()`. |
| `components` | `boolean` | `true` | Registers the three components and adds their stylesheet. |
| `keepTime` | `boolean` | `false` | Default `keepTime` for the composables that take it. |
| `reducedMotion` | `'never'`, `'system'` or `'always'` | `'never'` | When nanime animations jump to their end state. |

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nanime'],
  nanime: {
    keepTime: true,
    reducedMotion: 'system',
  },
})
```

With `composables: false`, import each composable from
`#nanime/composables`. With `components: false`, the module leaves the
three components and their stylesheet out of the app.

`keepTime` applies to `useAnimate`, `useAnimeTimeline` and
`useScrambleText`. A `keepTime` passed to one composable call wins over the
module option:

```ts
useAnimate(target, { x: 100 }, { keepTime: false })
```

`reducedMotion: 'system'` follows `prefers-reduced-motion`.
[Accessibility](/guides/accessibility) covers the values and shows a
runtime toggle.

## Scope defaults to part of the app

`provideAnimeDefaults()` sets defaults for everything rendered below the
component that calls it. It takes the component entries at the top level,
plus `composables`, `preset` and `keepTime`. It cannot set `transitions` or
`reducedMotion`, which stay app-wide.

```vue [components/SettingsPanel.vue]
<script setup lang="ts">
provideAnimeDefaults({
  transition: { animation: 'scale' },
  composables: { animate: { duration: 300 } },
  keepTime: true,
})
</script>
```

It also takes a getter that returns a defaults object, so the defaults can
follow reactive state:

```vue [components/ThemeScope.vue]
<script setup lang="ts">
const compact = ref(false)

provideAnimeDefaults(() => ({
  transition: { mode: compact.value ? 'out-in' : 'default' },
}))
</script>
```

## How a default is picked

Each default comes from the first source that sets it:

1. The prop on the component, or the parameters passed to the composable
   call.
2. The nearest `provideAnimeDefaults()` that sets that entry.
3. `nanime.components` or `nanime.composables` in `app.config.ts`.
4. The active [preset](/guides/presets).
5. The component's or composable's built-in default.

`keepTime` has its own chain: the composable's own option, the nearest
`provideAnimeDefaults()` that sets it, `nanime.keepTime` in `app.config.ts`,
the `keepTime` module option, then `false`.

### Component props resolve per prop

- A prop set to `undefined` falls through to the next source. The
  components declare boolean props with `default: undefined`, so passing
  `false` differs from leaving the prop out.
- A provider entry replaces the matching entry from an outer
  `provideAnimeDefaults()` call whole, and keeps the other components'
  entries.
- Within an entry, each prop sits over the `app.config.ts` value for that
  prop.
- Nothing merges deeper: `layoutOptions` and animation params replace the
  lower values whole.

### Composable entries are chosen whole

The first layer that sets a composable's entry is used whole, so a key left
`undefined` inside it falls to the built-in default, not to a lower layer.
A composable call then merges its parameters over the chosen entry by
top-level key.
