A preset bundles transition styles, component defaults and composable
defaults into one object. It sets entrances, exits, list moves, layout
changes and composable parameters together, so the motion of an app
comes from one place.

## Pick a built-in preset

| Preset | Motion | Enter / leave | Easing |
| :--- | :--- | :--- | :--- |
| `nanime/presets/formal` | Calm and precise, no overshoot | 240ms / 150ms | IBM Carbon productive curves |
| `nanime/presets/elegant` | Slow and soft, no overshoot | 450ms / 300ms | IBM Carbon expressive curves |
| `nanime/presets/playful` | Bouncy, overshoots about 12% on the way in | spring / 180ms | `spring()`, with `in(3)` for exits |

Each preset redefines the built-in style names (`fade`, `slide-up`,
`slide-down`, `slide-left`, `slide-right`, `scale`, `swap`) with its own
timing, and adds a `list` style that `<AnimeTransitionGroup>` uses by
default. It also sets the timing of `<AnimeLayoutGroup>`, the default
`ease` of `useAnimate()` and the release physics of `useDraggable()`.

The easings are named exports of each preset, so a curve can be used on
its own:

```ts
import { entrance } from 'nanime/presets/formal'
import { glide } from 'nanime/presets/elegant'
import { pop } from 'nanime/presets/playful'
```

Set it in `app.config.ts`. The config takes the imported object rather
than a preset name:

```ts [app/app.config.ts]
import formal from 'nanime/presets/formal'

export default defineAppConfig({
  nanime: {
    preset: formal,
  },
})
```

In a plain Vue app, pass the preset to `configureNanime()`. See
[Vue without Nuxt](/guides/vue).

A preset is the lowest layer of [the default order](/guides/configuration#how-a-default-is-picked).
It adds one rule of its own: style names resolve in `nanime.transitions`
first, then in the preset's `shared`, then in the built-in styles. Enter
and leave resolve independently, so one can come from the preset and the
other from a built-in.

## Write a preset

A preset is a plain object with three keys:

| Key | Holds | Required |
| :--- | :--- | :--- |
| `shared` | Named transition styles the preset adds, in the same shape as `nanime.transitions`. | No |
| `components` | Default props for `transition`, `transitionGroup` and `layoutGroup`. | Yes |
| `composables` | Default parameters for `animate` and `draggable`. | Yes |

`components` and `composables` must be present, and so must all three
entries inside `components`. Empty objects are fine. The app-wide preset
goes straight into `app.config.ts`:

```ts [app/app.config.ts]
export default defineAppConfig({
  nanime: {
    preset: {
      shared: {
        pop: {
          enter: { opacity: [0, 1], scale: [0.4, 1], duration: 240, ease: 'outBack(3)' },
          leave: { opacity: 0, scale: 0.4, duration: 140, ease: 'in(3)' },
          move: { duration: 200, ease: 'out(3)' },
        },
      },
      components: {
        transition: { animation: 'pop' },
        transitionGroup: { animation: 'pop' },
        layoutGroup: { layoutOptions: { duration: 400, ease: 'out(3)' } },
      },
      composables: {
        animate: { duration: 400, ease: 'out(3)' },
        draggable: { releaseEase: 'out(3)' },
      },
    },
  },
})
```

The names in `shared` work in the animation props of
[the components](/components/transitions), the same as a style from
`app.config.ts`. A name in both uses the `app.config.ts` style, and a
preset style with a built-in name replaces the built-in inside its scope.
`composables.animate` and `composables.draggable` are typed like
[`nanime.composables`](/guides/configuration#set-app-wide-defaults).

## Scope a preset to part of the app

`provideAnimeDefaults({ preset })` replaces the preset for everything
rendered below the component that calls it. The app-wide preset is not
used inside, and a preset from an outer scope is replaced whole.

The demo provides one of two presets to its own subtree. Both define a
style called `sway`, and the template never mentions a preset. `Snappy`
scales the box in over 220ms and moves list items over 150ms. `Glide`
slides it in over 700ms and moves items over 800ms. Picking a preset
replays the box and the list.

A built-in preset is scoped the same way:

```vue [components/MarketingSection.vue]
<script setup lang="ts">
import playful from 'nanime/presets/playful'

provideAnimeDefaults({ preset: playful })
</script>
```
