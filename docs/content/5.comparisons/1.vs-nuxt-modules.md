This page compares `nanime` with `@hypernym/nuxt-anime`, as of November
2026. The code samples also show AnimeJS on its own. If something is out
of date,
[open an issue](https://github.com/astraldev/nanime/issues){target="_blank"}.
For Vue packages, see
[Compared with Vue packages](/comparisons/vs-vue-packages).

## What does each module add to Nuxt?

[`@hypernym/nuxt-anime`](https://github.com/hypernym-studio/nuxt-anime){target="_blank"}
installs AnimeJS v3 and provides its `anime` function as `$anime`. With
`composables: true`, it also auto-imports the same function as
`useAnime`.

`nanime` is built on AnimeJS v4. It auto-imports composables such as
[`useAnimate`](/composables/use-animate) and registers
[transition components](/components/transition). v4 added WAAPI
animations, draggables, text splitting, scroll observers and layout
animations. `nanime` wraps each of these as a composable, such as
[`useDraggable`](/composables/use-draggable). Code written for v3 needs
changes to run on v4, because v4 split `anime()` into functions like
`animate()` and `createTimeline()`.

[`nuxt-animejs`](https://www.npmjs.com/package/nuxt-animejs){target="_blank"}
is a Nuxt 2 module with a `v-anime` directive. Its README says it is no
longer maintained and points to `@hypernym/nuxt-anime`.

## How do the modules compare?

| | `nanime` | `@hypernym/nuxt-anime` |
| :-- | :-- | :-- |
| AnimeJS version | [v4]{.comparison-good} | v3 |
| Latest release | [0.3.5, Oct 2026]{.comparison-good} | 2.1.1, Sep 2023 |
| Configuration needed | None | None |
| How components call AnimeJS | [Auto-imported composables]{.comparison-good} | `$anime` from `useNuxtApp()`, or `useAnime` with `composables: true` |
| Plain AnimeJS functions | Every v4 function from `animejs/*`, with the utils re-exported at `#nanime/utils` | Every v3 function on `$anime` |
| Waits for mount, cleans up on unmount | [Yes]{.comparison-good} | In your own `onMounted` and `onBeforeUnmount` |
| Rebuilds when a `ref` changes | [Yes]{.comparison-good}, and can keep the playhead with [`rebuild: 'keepTime'`](/guides/configuration#set-module-options) | In your own `watch` |
| Enter and leave animations | [`<AnimeTransition>` and `<AnimeTransitionGroup>`]{.comparison-good} | Vue's `<Transition>` hooks |
| [Reduced-motion setting](/guides/accessibility) | [Yes]{.comparison-good} | No |

::tip
Shaded cells mark the module that has the feature, on rows where the
two modules differ.
::

## Which should you pick?

- `nanime` for a Nuxt app on AnimeJS v4 that wants composables, cleanup
  and transition components.
- [`nanime/vue`](/guides/vue) for a Vue 3 app without Nuxt, with the
  same composables and components.
- AnimeJS on its own for one or two animations that never change.
- `@hypernym/nuxt-anime` for existing AnimeJS v3 code, or when `$anime`
  and your own lifecycle hooks are enough.

## How do you animate an element on mount?

::code-group
```vue [nanime]
<script setup lang="ts">
const card = useTemplateRef('card')

useAnimate(card, {
  opacity: [0, 1],
  translateY: [16, 0],
  duration: 400,
  ease: 'out(3)',
})
</script>

<template>
  <div ref="card" class="card" />
</template>
```

```vue [AnimeJS on its own]
<script setup lang="ts">
import { animate } from 'animejs/animation'
import type { JSAnimation } from 'animejs'

const card = useTemplateRef('card')
let animation: JSAnimation | undefined

onMounted(() => {
  if (!card.value) return
  animation = animate(card.value, {
    opacity: [0, 1],
    translateY: [16, 0],
    duration: 400,
    ease: 'out(3)',
  })
})

onBeforeUnmount(() => animation?.revert())
</script>

<template>
  <div ref="card" class="card" />
</template>
```

```vue [@hypernym/nuxt-anime]
<script setup lang="ts">
const { $anime } = useNuxtApp()

const card = useTemplateRef('card')

onMounted(() => {
  $anime({
    targets: card.value,
    opacity: [0, 1],
    translateY: [16, 0],
    duration: 400,
    easing: 'easeOutCubic',
  })
})

onBeforeUnmount(() => {
  if (card.value) $anime.remove(card.value)
})
</script>

<template>
  <div ref="card" class="card" />
</template>
```
::

v3 names the element option `targets` and the easing option
`easing`. v4 takes the element as the first argument and names the
easing option `ease`. `$anime.remove()` stops the animation and leaves
the card's inline styles in place, while `revert()` removes them.

## How do you rebuild an animation when a value changes?

::code-group
```vue [nanime]
<script setup lang="ts">
const box = useTemplateRef('box')
const distance = ref(100)

useAnimate(box, () => ({
  translateX: distance.value,
  alternate: true,
  loop: true,
  ease: 'inOut(2)',
}))
</script>

<template>
  <input v-model.number="distance" type="range" min="0" max="200">
  <div ref="box" class="box" />
</template>
```

```vue [AnimeJS on its own]
<script setup lang="ts">
import { animate } from 'animejs/animation'
import type { JSAnimation } from 'animejs'

const box = useTemplateRef('box')
const distance = ref(100)
let animation: JSAnimation | undefined

function play() {
  animation?.revert()
  if (!box.value) return
  animation = animate(box.value, {
    translateX: distance.value,
    alternate: true,
    loop: true,
    ease: 'inOut(2)',
  })
}

onMounted(play)
watch(distance, play)
onBeforeUnmount(() => animation?.revert())
</script>

<template>
  <input v-model.number="distance" type="range" min="0" max="200">
  <div ref="box" class="box" />
</template>
```

```vue [@hypernym/nuxt-anime]
<script setup lang="ts">
const { $anime } = useNuxtApp()

const box = useTemplateRef('box')
const distance = ref(100)

function play() {
  if (!box.value) return
  $anime.remove(box.value)
  $anime({
    targets: box.value,
    translateX: distance.value,
    direction: 'alternate',
    loop: true,
    easing: 'easeInOutQuad',
  })
}

onMounted(play)
watch(distance, play)
onBeforeUnmount(() => {
  if (box.value) $anime.remove(box.value)
})
</script>

<template>
  <input v-model.number="distance" type="range" min="0" max="200">
  <div ref="box" class="box" />
</template>
```
::

The rebuilt animation starts from the beginning. Pass `{ rebuild: 'keepTime' }` as the third argument to
continue from where the old one was. In the `@hypernym/nuxt-anime`
version, `$anime.remove()` leaves `translateX` where it was, so the new
animation starts from the box's current position.
