This page compares `nanime` with `@juleshry/vue-animejs` and `v-anime`,
as of November 2026. If something is out of date,
[open an issue](https://github.com/astraldev/nanime/issues){target="_blank"}.
For Nuxt modules, see
[Compared with Nuxt modules](/comparisons/vs-nuxt-modules).

## What does each package add?

[`vue-animejs`](https://github.com/juleshry/vue-animejs){target="_blank"}
wraps most of AnimeJS v4 in Vue composables, such as `useAnimate`,
`useTimeline` and `useTimer`. It also has five directives, such as
`v-animate`, and components for transitions, layout and scopes.

`nanime` covers a similar set of AnimeJS v4 APIs as composables and
transition components, as a Nuxt module or through
[`nanime/vue`](/guides/vue) in Vue apps without Nuxt.

[`v-anime`](https://github.com/Upperstrange/v-anime){target="_blank"}
wraps the AnimeJS v4 `createScope` function. Its `useAnime` runs your
functions once in `onMounted`, and its `useAnimeController` returns a
`trigger` function that calls a named scope method. The scope reverts on
unmount. Install `animejs` alongside it, since the package does not list
it as a dependency.

## How do the packages compare?

| | `nanime` | `vue-animejs` | `v-anime` |
| :-- | :-- | :-- | :-- |
| Latest release | 0.3.5, Oct 2026 | 1.6.0, Nov 2026 | 1.0.10, May 2025 |
| Setup in Nuxt | [Nuxt module with auto-imports]{.comparison-good} | Import in each component, or add to `imports.presets` | Import in each component |
| Waits for mount, cleans up on unmount | Yes | Yes | Yes |
| Rebuilds when a `ref` changes | [Yes]{.comparison-good} | [Yes]{.comparison-good} | No |
| Keeps the playhead on rebuild | [With `rebuild: 'keepTime'`]{.comparison-good} | No | No |
| What a composable returns | An object that forwards to the AnimeJS instance | Methods such as `play()`, and the instance in a ref | A `trigger` function |
| Composables for animate, timeline, WAAPI, draggable, scroll, text and layout | [Yes]{.comparison-good} | [Yes]{.comparison-good} | No, call AnimeJS inside the scope |

## Which should you pick?

- `nanime` for a Nuxt module with auto-imports, rebuilds that keep the
  playhead, or a reduced-motion setting.
- [`nanime/vue`](/guides/vue) for a Vue 3 app without Nuxt.
- `vue-animejs` for directives, `useTimer`, `useScope`, or starting
  styles rendered on the server.
- `v-anime` for animations kept in an AnimeJS scope and triggered by
  name.

## How do you animate an element on mount?

::code-group
```vue [nanime]
<script setup lang="ts">
const card = useTemplateRef('card')

useAnimate(card, {
  opacity: [0, 1],
  translateY: [16, 0],
  duration: 400,
})
</script>

<template>
  <div ref="card" class="card" />
</template>
```

```vue [vue-animejs]
<script setup lang="ts">
import { vAnimate } from '@juleshry/vue-animejs'
</script>

<template>
  <div
    v-animate="{ opacity: [0, 1], translateY: [16, 0], duration: 400 }"
    class="card"
  />
</template>
```

```vue [v-anime]
<script setup lang="ts">
import { animate } from 'animejs/animation'
import { useAnime } from 'v-anime'

const root = ref<HTMLElement | null>(null)
const scope = ref(null)

useAnime({
  root,
  scope,
  animeFunctions: [
    () => animate('.card', {
      opacity: [0, 1],
      translateY: [16, 0],
      duration: 400,
    }),
  ],
})
</script>

<template>
  <div ref="root">
    <div class="card" />
  </div>
</template>
```
::

The `vue-animejs` directive renders `opacity: 0` and the starting
`translateY` on the server, so the card does not flash before
hydration. The `nanime` and `v-anime` versions apply the starting styles
on mount, so the card shows its final state until then. The `v-anime`
scope resolves the `.card` selector inside `root` only.

## How do you rebuild an animation when a value changes?

::code-group
```vue [nanime]
<script setup lang="ts">
const box = useTemplateRef('box')
const distance = ref(100)

useAnimate(box, () => ({
  translateX: distance.value,
  alternate: true,
  loop: true,
}))
</script>

<template>
  <input v-model.number="distance" type="range" min="0" max="200">
  <div ref="box" class="box" />
</template>
```

```vue [vue-animejs]
<script setup lang="ts">
import { useAnimate } from '@juleshry/vue-animejs'

const box = useTemplateRef('box')
const distance = ref(100)

useAnimate(box, () => ({
  translateX: distance.value,
  alternate: true,
  loop: true,
}))
</script>

<template>
  <input v-model.number="distance" type="range" min="0" max="200">
  <div ref="box" class="box" />
</template>
```
::

Both packages rebuild the animation when `distance` changes, and the
rebuilt animation starts from the beginning. In `nanime`, pass
`{ rebuild: 'keepTime' }` as the third argument to continue from where
the old one was. `v-anime` runs its functions once, so it has no
version of this sample.
