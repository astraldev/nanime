# Documentation Rules

- **Framework**: Docus (Nuxt content-based docs)
- **Location**: `docs/content/` — numbered directories control nav order
- **Composable docs**: Use the `scaffold-composable-sample` skill for standard structure
- **MDC components**: Available via Docus — `::field-group`, `::render-code-block-preview`, etc.
- **Dev server**: `cd docs && pnpm dev` on port 3001
- **Each new composable** needs a corresponding page in `docs/content/2.composables/`
